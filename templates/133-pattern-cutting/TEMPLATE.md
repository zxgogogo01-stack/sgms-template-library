# 133 Pattern Cutting

以高级纸样裁床、牛皮纸、划粉线、裁片缺口和缝合边码为视觉语言的五页原创静态模板。异形纸样首屏、五段纸样札记、互指缝合边工具、折叠式制作责任页和缺片 404 均已完成；后续 AI 只替换变量、可见文字和项目示例，不需要重新搭建 UI、交互与响应式框架。

## 变量

- `{{LANG}}`：HTML 语言标签，如 `zh-CN`。
- `{{SITE_NAME}}`：站点名，建议 2–12 个汉字或 4–18 个拉丁字符。
- `{{BRAND_EN}}`：英文纸样室刊头，建议 4–16 个字符。
- `{{SITE_TAGLINE}}`：首屏短标签，建议 10–30 个字符。
- `{{HERO_DESCRIPTION}}`：首屏简介，建议 35–90 个字符。
- `{{ARTICLE_META}}`：文章日期、作者或版本信息，建议 10–35 个字符。
- `{{SITE_DESC}}`：页脚摘要，建议 20–60 个字符。
- `{{SITE_DOMAIN}}`：不含协议的域名。
- `{{CONTACT_CHANNEL}}`：公开联系渠道或联系页路径，不要放私人凭据。

## 页面与可直接使用的结构

- `index.html`：异形裁片首屏、四步缝边交接顺序和工具入口。
- `article.html`：五段纸样制作札记、阅读进度、主版图与交接摘要复制。
- `tool.html`：全局边码唯一性、互指关系、缺失对接、缝份一致与纸样状态审计器。
- `legal.html`：六项互斥展开的纸样、人体、面料、工艺、生产与权利边界。
- `404.html`：最多 80 个 Unicode 字符的本地栏目路由。

工具格式为 `裁片 | 边码 | 对接码 | 缝份mm | 状态`：接受 2–120 条非空记录，总长最多 6000 个 Unicode 字符。裁片名为 2–24 个 Unicode 字符并拒绝控制/格式字符；边码与对接码先执行 NFKC、转大写，随后必须为 2–12 位大写字母、数字或连字符。边码在清单中全局唯一，不能指向自己。缝份为 0–50 mm 的普通十进制，最多一位小数，不接受符号、前导零或多余精度；状态只能为“纸样 / 样衣 / 定版”。

工具按裁片名 NFKC、合并空格并忽略大小写，拒绝完全重复记录和重复边码。对每条边检查对接码是否存在、目标是否回指当前边，以及互指两侧缝份是否一致；同一对只生成一次缝份提示。未定版状态另行统计。界面最多显示前 40 条提示和前 40 条边码，复制完整报告会保留全部边码、关系与原始记录。

## 后续 AI 内容接入顺序

1. 全局替换上述变量，再重写可见标题、段落、示例数据与项目政策；不要删除既有 `data-pc133-*` 属性。
2. 保留五页、纸样首屏、折叠标签导航、文章层级、工具输出与移动端结构，不需要为新文案重做版式。
3. 用真实项目的边码规则、单位、缝份、状态、纸样、人体、面料、工艺、生产和权利政策替换示例。
4. 检查 title、description、canonical、Open Graph、robots 与 sitemap 的域名和路径。
5. 在 1440×1000 与 390×844 下逐页测试蓝图灯持久化、阅读进度、工具边界、完整复制、重置、互斥折叠和 404 路由。
