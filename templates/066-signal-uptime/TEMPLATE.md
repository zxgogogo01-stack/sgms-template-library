# 066-signal-uptime

独立的模拟信号实验室模板。首页用示波器、频道卡、开放回路提示和事件记录组织内容；文章页是一份分阶段事件复盘；工具页严格解析并合并服务窗口。所有 UI 使用 `sl66-` 专属命名空间，不依赖公共 CMS 样式、外部字体或外部图片。

## 后续 AI 内容接口

后续 AI 只替换变量和可见文字，不需要重做 UI、示波器视觉、响应式、主题、移动频道菜单或窗口合并算法：

1. 全局替换变量；保留 `sl66-` 类名、`data-*` 属性、控件 id 与五个页面文件名。
2. 首页频道和事件记录可以整项增减；状态词必须对应真实编辑状态，不得写成第三方平台实时状态。
3. 文章正文可替换，但保留触发、隔离、复核、关闭条件和预防项。
4. 服务窗口合并器只处理同一时间语义下的标记时间；不要把结果描述成跨时区、夏令时或真实系统可用性结论。
5. 动态列表继续使用安全 DOM 节点，不得改用 HTML 字符串拼接。

## 变量

- `%%LANG%%`：页面语言代码，例如 `zh-CN`。
- `%%SITE_NAME%%`：站点名称。
- `%%BRAND_EN%%`：页眉与页脚品牌名。
- `%%SITE_DOMAIN%%`：不含协议的正式域名。
- `%%SITE_TAGLINE%%`：品牌短句。
- `%%SITE_DESC%%`：首页搜索摘要。
- `%%SEO_TITLE%%`：首页 SEO 标题后半段。
- `%%HERO_EYEBROW%%`：首页主标题上方栏目短句。
- `%%HERO_TITLE%%`：首页唯一一级标题。
- `%%HERO_DESCRIPTION%%`：首页主标题说明。
- `%%HOME_FEATURED_LABEL%%`：首页频道区标签。
- `%%HOME_LINKS_LABEL%%`：首页快捷入口标签。
- `%%HOME_LATEST_LABEL%%`：首页事件记录标签。
- `%%CONTACT_EMAIL%%`：更正联系邮箱，必须换成真实可达地址或联系路径。

## 窗口合并边界

- 每个非空行必须严格为 `YYYY-MM-DD HH:MM | YYYY-MM-DD HH:MM`，日期范围 2000–2099，分钟精度。
- 开始必须早于结束；单个窗口跨度最多 366 天。
- 总输入最多 10000 个 Unicode 字符、100 个非空窗口。
- 所有时间按统一的连续分钟网格计算；重叠或首尾相接的窗口会合并，相接本身不增加重叠分钟。
- 独占时长是合并后覆盖分钟数；重叠时长是各原始窗口分钟之和减去独占分钟数。
