# 110-vermilion-couplet

## 模板定位

楹联档案、书法与刊刻工作室、地方文化、传统建筑题款、诗文校勘与非遗记录项目。视觉系统由朱砂套印、雁皮宣纸、松烟墨版、校样定位角、竖排联纸和圆形藏书章构成，不依赖外部图片也能形成完整高端界面。

## 后续 AI 接入规则（必须遵守）

本模板的 UI、响应式框架、组件层级、主题、交互、无障碍属性和安全输出已经完成。后续 AI **只替换变量与可见文字，不重建 UI，不改类名，不调整 DOM 结构，不改写 `impression.css` 或 `impression.js`**。新增楹联、堂记、校样或题款规则时，复制现有校样纸、正文段落、楹联行或边界组件，只替换内容与真实依据；不得在网站模板 UI 上再次浪费时间和 token。

## 文件

- `index.html`：朱印首屏、三次校样、四道印房工序与工具入口。
- `article.html`：采录、校对与核源堂记，含阅读进度、交接清单与复制。
- `tool.html`：批量楹联结构预检台，所有输入只在本地浏览器处理。
- `legal.html`：转录、题款角色、文字与影像权利、结构预检和修订边界。
- `404.html`：安全公开页检索与 noindex。
- `static/impression.css`：唯一视觉与响应式样式入口。
- `static/impression.js`：主题、菜单、进度、复制、楹联预检与 404 路由。

## 变量

`%%LANG%%`、`%%SITE_NAME%%`、`%%BRAND_EN%%`、`%%SITE_DOMAIN%%`、`%%SITE_TAGLINE%%`、`%%SITE_DESC%%`、`%%CONTACT_EMAIL%%`

发布前替换全部变量，并复核标题、描述、canonical、Open Graph、邮箱、楹联原文、上下联顺序、横批方向、异体与残缺、作者、出处、书写者、摄影者、作品与图像许可、版本和修订日期。

## 楹联结构预检台规则

- 每行格式：`校样 ID | 上联 | 下联 | 横批`。
- 接受 2–60 个非空校样；总输入不超过 12000 个 Unicode 字符。
- 校样 ID 2–16、上联 2–80、下联 2–80、横批 2–20 个 Unicode 字符；字段不得包含 Unicode 控制字符。
- ID 使用 NFKC、大小写与重复空白归一后不可重复。
- 上下联去除 Unicode 空白和标点后，各须保留 2–60 个内容字符；工具比较内容字符数量、标点类型与标点落点。
- 中文与全角兼容标点先经 NFKC 归一，顿号按逗号类落点处理；同位字符数量只是交接信息，不作为优劣判断。
- 上下联去除空白与标点、再按大小写归一后完全相同会提示重复；横批与任一联全文归一后相同也会提示复核。
- 界面最多展示前 40 条提示和 40 副楹联，复制报告保留全部结果。
- 机械预检不判断平仄、词性、声律、语义、典故、书法、文化适切性、作者、出处、原创性、许可或刊刻质量。

## 验收基线

- 五页各自只有一个 `h1`，1440×1000 与 390×844 均无页面级横向溢出。
- 移动目录首链聚焦，`Escape` 关闭并回焦；朱砂纸/墨版主题跨页保持。
- 正文进度到页尾为 100%；楹联交接、题款边界摘要与完整结构报告可复制。
- 动态楹联、提示和检索结果只使用安全 DOM 文本节点，不使用 `innerHTML`。
- 后续 AI 只能替换变量与文字，直接投入内容生产，不得重建模板 UI。
