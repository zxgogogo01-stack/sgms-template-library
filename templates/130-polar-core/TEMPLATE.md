# 130 Polar Core

极地冰芯档案馆主题的五页原创静态模板。顶部横向标尺导航、纵向冰芯剖面、非对称深度文章、表格式区间登记台与链路式责任边界均已完成；后续 AI 只需替换变量和可见文字，不需重做 UI。

## 直接替换的变量

- `%%LANG%%`：HTML 语言标签，如 `zh-CN`。
- `%%SITE_NAME%%`：站点名，建议 2–12 个汉字或 4–18 个拉丁字符。
- `%%BRAND_EN%%`：英文刊头，建议 4–16 个字符；手机端会安全截断过长文字。
- `%%SITE_TAGLINE%%`：首屏一句话标签，建议 12–32 个字符。
- `%%HERO_DESCRIPTION%%`：首屏简介，建议 35–90 个字符。
- `%%SITE_DESC%%`：页脚站点摘要，建议 20–60 个字符。
- `%%SITE_DOMAIN%%`：不含协议的域名。
- `%%CONTACT_CHANNEL%%`：公开联系渠道或联系页路径，不要放私人凭据。

## 页面与工具

- `index.html`：冰芯首屏、四段深度索引与登记台入口。
- `article.html`：深度标尺长文、抽象气泡层、阅读进度与交接摘要复制。
- `tool.html`：冰芯文字深度区间审计器。
- `legal.html`：六项互斥展开的保管边界和可复制摘要。
- `404.html`：最多 80 个 Unicode 字符的本地栏目路由。

工具输入格式为 `芯段 | 起始米 | 结束米 | 年代标签 | 状态`：2–120 条非空记录，总长不超过 6000 个 Unicode 字符。芯段名 2–24 字符，年代标签 2–32 字符，两者均拒绝 Unicode 控制/格式字符；深度为 0–5000 的无符号普通十进制数，最多两位小数，且起始小于结束；状态只能为“草录 / 复核 / 封存”。工具按 NFKC、忽略大小写与合并空格归一芯段，拒绝完全重复记录；每个芯段保留原始输入顺序，提示深度回退、区间重叠、区间间隙与未封存状态。界面最多显示前 40 条提示和前 40 个芯段，“复制完整报告”保留所有结果。

## 发布前必做

1. 全局替换上述变量，检查标题、描述、canonical、Open Graph、robots 和 sitemap。
2. 用项目当前事实重写所有冰芯、深度、年代、采样、储存、实验与权利文字；示例数字不是真实记录。
3. 用项目专用的隐私、数据保管、冷链、实验室、知识产权和发布政策替换边界文案。
4. 在 1440×1000 与 390×844 下逐页检查排版、键盘焦点、对比度、主题持久化、阅读进度、工具边界、复制、重置、互斥折叠和 404 路由。
5. 本模板零外链、零 CDN、零外部字体和图片；如后续添加素材，发布前确认授权、隐私、性能与来源。

## 责任边界

本地工具只检查文字字段、十进制深度、输入顺序、区间关系与档案状态。它不读取样品、坐标、冷链、实验或现场数据，不推断地层、年代、气候、样品质量、安全、权利或发布批准。
