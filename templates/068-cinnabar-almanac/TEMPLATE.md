# 068-cinnabar-almanac（忠实静态化自军哥 home_almanac）

## 适合什么站

适合资讯、公告、知识库和月度归档站点：双线封面、栏目图例、大日号置顶、日历格、点线议程与页边笔记形成完整年鉴结构。

## 复刻说明

- 首页完整保留军哥 `home_almanac` 的 `al-*` 类名、嵌套和区域顺序：封面、栏目图例、置顶红字、月份日历、议程和页边笔记。
- `public.css` 是军哥公共样式原样副本；`style.css` 继续提供宣纸米白、朱砂红和宋体视觉，旧类名仅作兼容样式钩子。
- Go 条件、循环、日期切片和内容 URL 已静态化；日历中的 7 条文章也全部同步到议程列表，保持源模板两处使用同一批文章的关系。
- 桌面和 390px 手机视口均需保持日号、图钉、点线引导与栏目标签清晰，无横向溢出。

## 静态化边界

- 不加入源模板不存在的邀请码、复制按钮或营销印章卡。
- 示例链接均指向套件内页面；生产接入时应同步维护日历格和议程条目。

## 页面与文件

`index.html` / `article.html` / `tool.html` / `legal.html` / `404.html` / `robots.txt` / `sitemap.xml`；样式为 `public.css` 与 `style.css`，交互为 `turn.js`。

## 占位符清单（`__x__` 小写双下划线语法）

`__site_name__`、`__brand_en__`、`__site_domain__`、`__site_tagline__`、`__site_desc__`、`__contact_email__`、`__lang__`

## 可调项

- 日历格与议程条必须使用同一批文章，日期和栏目同步更新；封面卷名按站点时间调整。
- 色彩与列数可调，但双线封面、大日号、图钉和点线 leader 是本模板的主要识别特征。
