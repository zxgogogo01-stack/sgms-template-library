# 155 Kumiko Lattice

一套可直接换字使用的高端组子格构档案模板。品牌、导航、首页、文章、本地工具、责任页、404、robots、sitemap 与独立静态资源均已搭好；后续 AI 只替换变量和正文，不需要重做 UI。

## 替换变量

- `{{LANG}}`：页面语言代码，例如 `zh-Hans`
- `{{SITE_NAME}}`：站点名称
- `{{SITE_DOMAIN}}`：域名，不含协议和路径
- `{{SITE_DESC}}`：站点简介
- `{{ATELIER_MARK}}`：2–8 字符短标或字母标
- `{{ATELIER_TAGLINE}}`：首页内部短标语
- `{{ISSUE_LABEL}}`：资料期次或专题标签
- `{{JOINERY_CODE}}`：首页可复制的格构编号；它不是邀请码，也不应自动变成外链
- `{{HERO_DESCRIPTION}}`：首屏说明，建议 38–90 个中文字符
- `{{ARTICLE_META}}`：文章版本、期次或更新标签
- `{{CONTACT_CHANNEL}}`：联系渠道展示文字

全仓搜索 `{{` 即可定位变量。替换时保持 HTML 转义，不写入未经核实的品牌、工匠、项目、图样、木材、尺寸、性能或结论。

## 完整页面

- `index.html`：双幅格构厅、CSS 组子屏风、完整内容入口与可复制格构编号。
- `article.html`：固定木札目录与六节完整长文骨架，直接替换标题、段落和清单。
- `tool.html`：本地板块模数审计器；除非业务规则确实改变，不要改选择器、字段或状态机。
- `legal.html`：六个责任格，覆盖资料、材料、结构、加工安装、安全与权利。
- `404.html`：独立断格视觉与本地关键词路由。
- `robots.txt` / `sitemap.xml`：上线前替换域名，确认四个 canonical 可索引页面全部进入 sitemap。

## 工具固定格式

每行：`板块号 | 纹样 | 横宽mm | 纵高mm | 横节距mm | 纵节距mm | 状态`

- 2–80 条非空记录，总输入不超过 8000 个 Unicode 字符。
- 板块号 2–20 个 Unicode 字符；先拒绝控制/格式字符，再做 NFKC、大小写与重复空白归一；归一后全局唯一。
- 纹样只能是：`麻叶`、`胡麻`、`桔梗`、`角麻`、`其他`。
- 横宽和纵高为 1–100000mm、横纵节距为 1–10000mm 的普通十进制整数；拒绝符号、小数、指数和多位前导零。
- 状态只能是：`草排`、`校核`、`定稿`。
- 每块板分别计算 `横宽 % 横节距` 与 `纵高 % 纵节距`；任一余数不为零就形成一项几何提示。
- 同一纹样的第一块板作为本次内部参照；后续同纹样板块的横纵节距不同就逐块形成漂移提示。该规则只检查清单一致性，不是传统工艺规范。
- 每块板的完整格数为 `floor(横宽/横节距) × floor(纵高/纵节距)`，全表安全整数加总；严格超过用户上限才提示，等于上限通过。上限范围为 1–1000000000000。
- 每条 `草排` 各形成一项状态提示。
- 结果状态为 `GRID CLEAR`、`GEOMETRY FLAGS N`、`STATUS FLAGS N` 或 `REVIEW N`。
- 界面最多显示前 40 条提示与前 40 条板块，完整复制保留全部记录和提示；任一输入变化都会使旧报告失效。

## 视觉系统

- 原创组子工坊语言：米纸、雪松红、深靛、旧金、鼠尾草与无圆角木作结构。
- 首屏以全幅 CSS 格构屏和独立内容开间对切；文章使用固定木札目录，工具使用双色工作台，法律页使用六格责任板。
- 日/夜主题重新配置纸面、木色、阴影与对比，不做机械反色。
- 所有格线、六边形、断格与 404 视觉均由 CSS 绘制，无外部字体、图片、图标、CDN 或跟踪脚本。
- 类名 `km155-` 与 `data-km155-*` 是独立命名空间，不要换成其他模板类名。

## 安全与发布

- 用户输入只通过 `textContent` 写回 DOM；预览样式值只来自通过白名单或整数范围校验的数据。不要改成 `innerHTML`、`insertAdjacentHTML`、内联事件或动态脚本。
- 页面不读取或上传图样、CAD、BOM、模型、项目、材料或设备数据。
- 模数与余数结果不构成木材、结构、连接、加工、安装、质量、安全、法规、知识产权或发布批准。
- 首页、导航、工具、法律页、404 和页脚不放返佣直链。若业务需要转换链接，只在经核实的高意图正文中按站点治理规则单独加入。
- 上线前检查标题、描述、canonical、sitemap、联系渠道、隐私、事实、权利、日期和全部变量。

## 交付检查

1. 五页各一个 `h1`，键盘焦点可见，360px 以上无横向溢出，操作控件至少 44×44px。
2. 日/夜主题持久化；复制、预设、生成、失效、重置和 404 路由均实际测试。
3. 工具覆盖空值、字段数、格式、边界、NFKC 重复、白名单、余数、节距漂移、格数等于/严格超过、80 条上限和 XSS 文本化。
4. 运行 JS 语法、仓库验证、严格审计、全库相似度、秘密与占位扫描。
5. 保留独立 CSS/JS，不复用相邻模板的首屏、导航、卡片骨架或工具算法。
