# 142 Gem Setting

以珠宝镶嵌台、放大镜、抽象宝石切面、深绿天鹅绒、祖母绿、石榴红、香槟金与荧光黄绿为视觉语言的五页原创静态模板。首页切面首屏、五段工坊札记、精确整数配石台、六格责任匣和空镶口 404 均已完成；后续 AI 只需替换变量、可见文字和演示数据，不需要重新搭建 UI、交互或响应式框架。

## 变量

- `{{LANG}}`：HTML 语言标签，如 `zh-CN`。
- `{{SITE_NAME}}`：站点名，建议 2–12 个汉字或 4–18 个拉丁字符。
- `{{BRAND_EN}}`：英文工坊刊头，建议 4–16 个字符。
- `{{SITE_TAGLINE}}`：首屏短句，建议 10–30 个字符。
- `{{HERO_DESCRIPTION}}`：首屏简介，建议 35–90 个字符。
- `{{STONE_SAMPLE}}`：纯演示宝石或物件编号，建议 2–10 个字符；不得误写为真实证书或库存证明。
- `{{ARCHIVE_CODE}}`：首页可复制的演示档案编号，不得冒充证书、鉴定结果或所有权凭据。
- `{{ARTICLE_META}}`：文章日期、作者或版本信息，建议 10–35 个字符。
- `{{SITE_DESC}}`：页脚摘要，建议 20–60 个字符。
- `{{SITE_DOMAIN}}`：不含协议的域名。
- `{{CONTACT_CHANNEL}}`：公开联系渠道或联系页路径，不要放私人凭据。

## 页面与完整框架

- `index.html`：固定竖向镶台导航、放大镜与抽象祖母绿首屏、三张工坊视图、铭文带、四切面信息结构和可复制档案编号。
- `article.html`：来源、数量、镶位、记录与交接五段札记，含阅读进度、章节索引、首字下沉、切面示意和摘要复制。
- `tool.html`：逐批次可用、镶位、预留、用户复核线、整数余量和文档状态报告。
- `legal.html`：六格互斥展开的身份鉴定、来源证书、库存数量、工艺安全、价格交易与隐私权利责任匣。
- `404.html`：最多 80 个 Unicode 字符的本地档案路由，用户输入只通过 `textContent` 反馈。

工具格式为 `托位 | 可用 | 镶位 | 预留 | 复核线 | 状态`：接受 2–100 条非空记录，总长最多 6000 个 Unicode 字符。托位执行 NFKC、去除首尾空格、合并内部空格并忽略大小写后必须全局唯一，长度为 2–24 个 Unicode 字符，拒绝控制字符和格式字符；完全相同与规范化后重复分别报错。

可用、预留与复核线必须为 0–9999 的普通十进制整数；镶位必须为 1–9999 的普通十进制整数，均不接受正负号、指数、小数或前导零。状态只能为“草稿 / 已核 / 已封”。剩余数量严格等于 `可用 − 镶位 − 预留`，只执行整数运算。

剩余数量小于 0 时生成缺口提示；剩余数量大于等于 0 且小于等于用户输入复核线时生成触线提示。每个非“已封”记录另生成一项状态提示。复核线完全来自用户输入，不是页面给出的安全库存、采购或质量建议。总览显示所有批次中最紧的整数余量和总镶位数。界面最多显示前 40 项提示和前 40 个批次，复制完整交接保留全部记录。

## 后续 AI 内容接入顺序

1. 全局替换上述变量，再重写可见标题、段落、演示数据和项目政策；不要删除既有 `data-gs142-*` 属性。
2. 保留五页、放大镜宝石首屏、竖向镶台导航、文章结构、配石工具、互斥责任匣和移动端框架，不需要为新文案重做 UI。
3. 用经过确认的托位、可用数量、镶位数量、预留、复核线和状态替换示例；不要让后续 AI 从名称、外观或历史记录猜测真实宝石、规格、库存或价值。
4. 检查 title、description、canonical、Open Graph、robots 与 sitemap 的域名和路径。
5. 在 1440×1000 与 390×844 下逐页测试珠宝灯明暗持久化、阅读进度、整数边界、复核线包含边界、完整复制、重置、互斥责任匣和 404 路由。
