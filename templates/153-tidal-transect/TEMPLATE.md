# 153 Tidal Transect

一套可直接换字使用的潮间带样方档案模板。首页、文章页、本地工具、责任页、404、robots、sitemap、品牌槽、导航、页脚和独立静态资源均已搭好；后续 AI 不需要重做 UI。

## 替换变量

- `{{LANG}}`：页面语言代码，例如 `zh-Hans`
- `{{SITE_NAME}}`：站点名称
- `{{SITE_DOMAIN}}`：域名，不含协议和路径
- `{{SITE_DESC}}`：站点简介
- `{{FIELD_MARK}}`：2–6 字符短标或字母标
- `{{ISSUE_LABEL}}`：本期资料标签
- `{{PANEL_CODE}}`：首页可复制的样带编号；它不是邀请码，也不应自动变成外链
- `{{HERO_DESCRIPTION}}`：首屏说明，建议 38–90 个中文字符
- `{{ARTICLE_META}}`：文章期次、地点口径或更新标签
- `{{CONTACT_CHANNEL}}`：联系渠道，可写邮箱展示文字或编辑部说明

全仓搜索 `{{` 即可定位变量。替换时保持 HTML 转义，不把未经核实的地点、人员、物种、比率或结论写入模板。

## 页面与内容槽

- `index.html`：高端潮间带样带首页；可复制样带编号，四个内容入口可扩成文章、工具和责任枢纽。
- `article.html`：六节完整长文骨架；直接替换标题、段落和清单，保留单一 `h1` 与逐级标题。
- `tool.html`：本地样方覆盖审计台；算法和 UI 已完成，除非业务规则确实改变，不要改选择器和状态机。
- `legal.html`：六层责任边界；应按真实业务补充方法、隐私、许可和发布规则，不要删成一句免责声明。
- `404.html`：独立 404；线索只在浏览器本地匹配并跳回已有页面。
- `robots.txt` / `sitemap.xml`：上线前替换域名，并确认四个可索引 canonical URL 与 sitemap 完全一致。

## 工具固定格式

每行：`样方号 | 潮位带 | 生物组 | 覆盖率% | 样本数 | 状态`

- 2–80 条非空记录，总输入不超过 8000 个 Unicode 字符。
- 样方号 2–20 个 Unicode 字符；先拒绝控制/格式字符，再做 NFKC、大小写和重复空白归一。
- 潮位带只能是：`高潮带`、`中潮带`、`低潮带`、`潮下带`。
- 生物组只能是：`藻类`、`贝类`、`甲壳类`、`棘皮类`、`其他`。
- 覆盖率为 0–100 的普通十进制整数；样本数为 0–999 的普通十进制整数。拒绝符号、小数、指数和多位前导零。
- 状态只能是：`草记`、`复核`、`锁定`。
- 同一样方可以出现多个生物组，但潮位带必须一致；同一样方与生物组组合不得重复。
- 同一样方覆盖合计严格大于 100 才提示；等于 100 通过。
- 单一生物组覆盖份额使用整数乘法与用户上限精确比较；严格超过才提示，等于边界通过。总覆盖为零时不做份额判断。
- 缺少任一潮位带各形成一项缺口；每条 `草记` 各形成一项状态提示。
- 结果状态为 `TRANSECT CLEAR`、`COVER FLAGS N`、`STATUS FLAGS N` 或 `REVIEW N`。
- 页面只显示前 40 条提示，但复制报告保留全部记录和提示；任一输入变化都会使旧报告失效。

## 视觉系统

- 版式：原创建筑化海岸切片，桌面首屏采用编号边轨、四层潮位带和右侧宣言三段结构；移动端改为纵向样带。
- 色板：石灰纸、深海绿、群青、珊瑚、海藻绿、沙金；夜潮模式不是简单反色。
- 图形：全部由 CSS 绘制，无外部字体、图片、图标、CDN 或跟踪脚本。
- 命名空间：`tp153-` 与 `data-tp153-*` 独立使用，不应换成其他模板的类名。

## 安全与发布

- 用户输入只通过 `textContent` 写回 DOM；不要改成 `innerHTML`、`insertAdjacentHTML`、内联事件或动态脚本。
- 工具不上传数据，也不读取位置、图像、样本或设备。
- 内部覆盖算术不构成物种鉴定、生态结论、调查设计、统计推断、现场安全、许可或发布批准。
- 首页、导航、工具、法律页、404 和页脚不放返佣直链。若业务需要转换链接，只能在经核实的高意图正文中按站点治理规则单独加入。
- 上线前检查标题、描述、canonical、sitemap、联系渠道、隐私、事实、权利、日期和所有变量。

## 交付检查

1. 五页各自只有一个 `h1`，键盘焦点可见，360px 以上无横向溢出，所有操作控件至少 44×44px。
2. 日潮/夜潮切换持久化；复制、预设、生成、输入失效、重置和 404 路由均实际测试。
3. 工具至少覆盖空值、格式、边界、重复、潮带不一致、覆盖过载、份额相等/严格超过、80 条上限和 XSS 文本化。
4. 运行 `node --check static/tidal-transect.js`、仓库验证、严格审计、全库相似度和秘密扫描。
5. 保留独立 CSS/JS，不引入共享皮肤，不复用相邻模板的首屏、导航、卡片骨架或工具算法。
