# 016-gleam-tracker

## 适合什么站

指标观察、数据周报、研究快照与轻量数据看板：深色观测侧栏、编辑式首屏、可筛选指标表、观察摘要和口径档案组成完整信息链路。

## 视觉与结构

- 桌面端为 `278px` 深色观测侧栏 + 弹性主区，侧栏 sticky；移动端转为横向导航
- 高对比海绿 / 青柠信号色，尖角面板、细线分隔、等宽数据标签，保留独立的“微光观测台”身份
- 首页包含状态快照、邀请码面板、趋势筛选、核心指标表、观察摘要与方法论入口
- `article.html` 是完整口径档案；`tool.html` 是本地目标距离计算；`legal.html` 与 `404.html` 延续同一套视觉系统
- 960px 与 620px 两级响应式重排，支持系统深色模式与减少动态效果偏好

## 占位符清单（`%X%` 语法）

| 占位符 | 用途 |
|---|---|
| `%SITE_NAME%` | 站点名称 |
| `%SITE_DOMAIN%` | 域名，不含协议 |
| `%SITE_TAGLINE%` | 首页一句话说明 |
| `%SITE_DESC%` | 页面描述 |
| `%INVITE_CODE%` | 邀请码 |
| `%COMPLIANCE_NOTE%` | 邀请码与第三方内容的合规说明 |
| `%CONTACT_EMAIL%` | 联系邮箱 |
| `%EFFECTIVE_DATE%` | 站点说明生效日期 |
| `%LANG%` | `html lang`，如 `zh-CN` |

## 后续 AI 的文字接入顺序

这套数据看板的五页 UI、指标筛选、邀请码复制和计算器都已完成。后续 AI 只替换占位符和文字/数据内容，不要重写布局、CSS 类名或页内脚本：

1. 先在所有页面统一替换上面的 9 个占位符，尤其保持域名、邀请码、合规说明、生效日期和联系方式一致。
2. 再填写 `index.html` 的快照日期、四项指标、数值、变化方向、观察摘要与核对时间；每行通过 `data-trend="rising|flat|declining"` 参与筛选，新增数据时必须同步填写。
3. 将 `article.html` 的指标定义、窗口、时区、来源和复核节奏改为与首页逐项对应的正式口径档案。
4. 在 `tool.html` 只修改工具说明与示例，保留 `span-calc`、`sc-now`、`sc-aim`、`sc-go`、`sc-out`；在 `legal.html` 填写数据性质、风险边界、第三方披露和更正渠道。
5. 完成后实测邀请码复制、全部/上行/持平/回落四类筛选，以及计算器的双空值、单缺项、零值、非有限值、上涨、回落和相等结果；再检查 390px 页面与指标横向表格。

邀请码区可整块删除；如删除，需同时移除首页复制脚本与 `legal.html` 中的相关说明。
