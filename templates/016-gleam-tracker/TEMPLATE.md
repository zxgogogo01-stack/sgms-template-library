# 016-gleam-tracker

## 适合什么站

指标观察、数据周报、研究快照与轻量数据看板：深色观测侧栏、编辑式首屏、可筛选指标表、观察摘要和口径档案组成完整信息链路。

## 视觉与结构

- 桌面端为 `278px` 深色观测侧栏 + 弹性主区，侧栏 sticky；移动端转为横向导航
- 高对比海绿 / 青柠信号色，尖角面板、细线分隔、等宽数据标签，保留独立的“微光观测台”身份
- 首页包含状态快照、邀请码面板、趋势筛选、核心指标表、观察摘要与方法论入口
- `article.html` 是完整口径档案；`tool.html` 是本地目标距离计算；`legal.html` 与 `404.html` 延续同一套视觉系统
- 960px 与 620px 两级响应式重排，支持系统深色模式与减少动态效果偏好

## 占位符清单（`%X%` 语法）

| 占位符 | 用途 |
|---|---|
| `%SITE_NAME%` | 站点名称 |
| `%SITE_DOMAIN%` | 域名，不含协议 |
| `%SITE_TAGLINE%` | 首页一句话说明 |
| `%SITE_DESC%` | 页面描述 |
| `%INVITE_CODE%` | 邀请码 |
| `%COMPLIANCE_NOTE%` | 邀请码与第三方内容的合规说明 |
| `%CONTACT_EMAIL%` | 联系邮箱 |
| `%EFFECTIVE_DATE%` | 站点说明生效日期 |
| `%LANG%` | `html lang`，如 `zh-CN` |

## 内容替换

- 首页四项指标、数值、变化方向、摘要与核对时间均为结构示例，上线前必须替换为核实数据
- 指标行通过 `data-trend="rising|flat|declining"` 参与趋势筛选，新增数据时同步填写
- `article.html` 中的定义、窗口、时区与来源说明需与首页指标一一对应
- 邀请码区可整块删除；同时移除首页复制脚本与 `legal.html` 中的相关说明

## 交互与验收

- 首页：复制反馈、趋势筛选、筛选状态播报
- 工具页：空值和零值错误反馈、无效字段聚焦、上涨 / 回落 / 相等三类结果
- 全站：可见键盘焦点、当前导航状态、浅色与深色模式、390px 移动端无页面级横向溢出
