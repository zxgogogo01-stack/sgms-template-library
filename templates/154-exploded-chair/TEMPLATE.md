# 154 Exploded Chair

一套可直接换字使用的高端爆炸图装配档案模板。品牌、导航、首页、文章、本地工具、责任页、404、robots、sitemap 与独立静态资源均已搭好；后续 AI 只替换变量和正文，不需要重做 UI。

## 替换变量

- `{{LANG}}`：页面语言代码，例如 `zh-Hans`
- `{{SITE_NAME}}`：站点名称
- `{{SITE_DOMAIN}}`：域名，不含协议和路径
- `{{SITE_DESC}}`：站点简介
- `{{STUDIO_MARK}}`：2–6 字符短标或字母标
- `{{STUDIO_TAGLINE}}`：首页底部短标语
- `{{ISSUE_LABEL}}`：资料期次或专题标签
- `{{PANEL_CODE}}`：首页可复制的装配编号；它不是邀请码，也不应自动变成外链
- `{{HERO_DESCRIPTION}}`：首屏说明，建议 38–90 个中文字符
- `{{ARTICLE_META}}`：文章版本、期次或更新标签
- `{{CONTACT_CHANNEL}}`：联系渠道展示文字

全仓搜索 `{{` 即可定位变量。替换时保持 HTML 转义，不写入未经核实的品牌、设计师、产品、材料、规格或结论。

## 完整页面

- `index.html`：全屏工业设计装配厅，右侧竖向导航、CSS 爆炸椅与可复制装配编号已完成。
- `article.html`：六节完整长文骨架，直接替换标题、段落和清单，保留单一 `h1` 与逐级标题。
- `tool.html`：本地父子关系与名义质量审计器；除非业务规则确实改变，不要改选择器、字段或状态机。
- `legal.html`：六张责任图纸，覆盖资料、结构、人体工学、制造、安全与权利。
- `404.html`：独立构件散落视觉与本地关键词路由。
- `robots.txt` / `sitemap.xml`：上线前替换域名，确认四个 canonical 可索引页面全部进入 sitemap。

## 工具固定格式

每行：`部件号 | 材料 | 父部件 | 数量 | 单件质量g | 状态`

- 2–80 条非空记录，总输入不超过 8000 个 Unicode 字符。
- 部件号 2–20 个 Unicode 字符；先拒绝控制/格式字符，再做 NFKC、大小写与重复空白归一；归一后全局唯一，且不得使用保留字 `ROOT`。
- 材料只能是：`榉木`、`钢`、`铝`、`皮革`、`织物`、`其他`。
- 父部件只能是大写 `ROOT` 或清单内的部件号；允许前向引用。
- 数量为 1–99、单件质量为 1–100000g 的普通十进制整数。拒绝符号、小数、指数和多位前导零。
- 状态只能是：`草模`、`校核`、`定版`。
- 全部读取后检查根构件数量恰好为一、缺失父件、自指和父链闭环。
- 名义总质量为每条 `数量 × 单件质量` 的精确整数和；严格超过用户上限才提示，等于上限通过。
- 每条 `草模` 各形成一项状态提示。
- 结果状态为 `ASSEMBLY CLEAR`、`ASSEMBLY FLAGS N`、`STATUS FLAGS N` 或 `REVIEW N`。
- 界面最多显示前 40 条提示与前 40 条父子关系，完整复制保留全部记录和提示；任一输入变化都会使旧报告失效。

## 视觉系统

- 原创爆炸图工业设计语言：炭黑工作室、骨白图纸、氧化红、国际蓝、原色黄与铬灰。
- 桌面使用常驻右侧竖向导航；移动端改为顶部品牌条和横向四格导航，与相邻模板的顶部横栏和潮带切片不同。
- 椅子、构件、尺寸线与 404 全部由 CSS 绘制，无外部字体、图片、图标、CDN 或跟踪脚本。
- 类名 `ec154-` 与 `data-ec154-*` 是独立命名空间，不要换成其他模板类名。

## 安全与发布

- 用户输入只通过 `textContent` 写回 DOM；不要改成 `innerHTML`、`insertAdjacentHTML`、内联事件或动态脚本。
- 页面不读取或上传图纸、CAD、BOM、模型、产品、材料或设备数据。
- 父子关系和名义质量不构成结构、人体工学、材料、制造、质量、安全、法规、知识产权或发布批准。
- 首页、导航、工具、法律页、404 和页脚不放返佣直链。若业务需要转换链接，只在经核实的高意图正文中按站点治理规则单独加入。
- 上线前检查标题、描述、canonical、sitemap、联系渠道、隐私、事实、权利、日期和全部变量。

## 交付检查

1. 五页各一个 `h1`，键盘焦点可见，360px 以上无横向溢出，操作控件至少 44×44px。
2. 工作室/图纸灯主题持久化；复制、预设、生成、失效、重置和 404 路由均实际测试。
3. 工具覆盖空值、格式、边界、重复、ROOT 保留字、缺失父件、自指、多根、零根、闭环、质量等于/严格超过、80 条上限和 XSS 文本化。
4. 运行 JS 语法、仓库验证、严格审计、全库相似度、秘密与占位扫描。
5. 保留独立 CSS/JS，不复用相邻模板的首屏、导航、卡片骨架或工具算法。
