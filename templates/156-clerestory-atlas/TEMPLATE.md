# 156 Clerestory Atlas

一套可直接换字使用的高端高窗采光图集模板。品牌、导航、首页、文章、本地工具、责任页、404、robots、sitemap 与独立静态资源均已搭好；后续 AI 只替换变量和正文，不需要在网站模板 UI 上重新设计或消耗额外 token。

## 替换变量

- `{{LANG}}`：页面语言代码，例如 `zh-Hans`
- `{{SITE_NAME}}`：站点名称
- `{{SITE_DOMAIN}}`：域名，不含协议和路径
- `{{SITE_DESC}}`：站点简介
- `{{STUDIO_MONOGRAM}}`：2–8 字符品牌短标或字母标
- `{{EDITION_LABEL}}`：资料期次、栏目或专题标签
- `{{HERO_STATEMENT}}`：首屏陈述，建议 38–90 个中文字符
- `{{DAYLIGHT_CODE}}`：首页可复制的观测编号；它不是邀请码，也不应自动变成外链
- `{{ARTICLE_META}}`：文章版本、期次或更新标签
- `{{CONTACT_CHANNEL}}`：联系渠道展示文字

全仓搜索 `{{` 即可定位变量。替换时保持 HTML 转义，不写入未经核实的建筑、项目、客户、仪器、天气、测量、材料、性能、规范或结论。

## 完整页面

- `index.html`：建筑剖面式光井、CSS 高窗日照视觉、完整内容入口与可复制观测编号。
- `article.html`：六段完整观测长文、固定横向现场索引、阅读进度和摘要复制。
- `tool.html`：本地采样序列照度台；除非业务规则确实改变，不要改选择器、字段或状态机。
- `legal.html`：六个责任面，覆盖资料、测量、物理、设计施工、法规安全和隐私权利。
- `404.html`：独立断光视觉与本地关键词路由。
- `robots.txt` / `sitemap.xml`：上线前替换域名，确认四个 canonical 可索引页面全部进入 sitemap。

## 工具固定格式

每行：`区域 | 时刻 | 朝向 | 外照度lx | 内照度lx | 状态`

- 2–80 条非空记录，总输入不超过 8000 个 Unicode 字符。
- 区域归一后为 2–20 个 Unicode 字符；先拒绝控制/格式字符，再做 NFKC、大小写与重复空白归一。
- 同一区域与时刻的组合归一后必须全局唯一；区域本身可在不同时刻重复。
- 时刻必须为 `00:00–23:59` 的两位 `HH:MM`；朝向只能是北、东北、东、东南、南、西南、西、西北。
- 外照度为 1–1000000lx，内照度为 0–1000000lx 的无符号普通十进制整数；拒绝正负号、小数、指数和多位前导零。
- 状态只能是：`草测`、`复核`、`归档`。
- 用户输入照度因子下界、上界 0–10000 基点及最大间隔 1–1440 分钟；下界不能大于上界。
- 每条照度因子以 `内照度 × 10000 / 外照度` 定义；区间判断用整数交叉乘法，等于上下界通过，严格越界才提示。显示值四舍五入到整数基点。
- 同一区域按录入顺序检查：时刻必须严格递增；相邻正向间隔严格超过用户上限才提示；朝向与该区域首条不一致时提示。跨日观测应拆分，不自动回绕。
- 全表加权因子为 `内照度总和 × 10000 / 外照度总和` 的整数基点显示值；它只描述本次输入。
- 每条 `草测` 各形成一项状态提示。
- 结果状态为 `SUNPATH CLEAR`、`BAND FLAGS N`、`SEQUENCE FLAGS N`、`STATUS FLAGS N` 或 `REVIEW N`。
- 界面最多显示前 40 条提示与前 40 条采样，完整复制保留全部记录和提示；任一输入变化都会使旧报告失效。

## 视觉系统

- 原创高窗建筑图集语言：粉笔灰、纸白、炭黑、日光黄、群青、陶土红和暮紫。
- 首屏把竖向时刻尺、杂志式宣言、CSS 日光剖面和悬浮观测票据组合为不对称三联面；不是相邻模板的屏风、右侧栏或居中拱顶。
- 首页入口使用横向编号档案带；文章使用可横向阅读的现场索引；工具使用炭黑实时光束面；法律页是六块无圆角建筑责任面。
- 正午/暮色主题分别调校纸面、日光、阴影和对比，不做机械反色。
- 全部日轮、光束、高窗、标尺与 404 断光视觉均由 CSS 绘制，无外部字体、图片、图标、CDN 或跟踪脚本。
- 类名 `sv156-` 与 `data-sv156-*` 是独立命名空间，不要换成其他模板类名。

## 安全与发布

- 用户输入只通过 `textContent` 写回 DOM；预览样式只使用方位白名单映射和校验后派生的有界整数。不要改成 `innerHTML`、`insertAdjacentHTML`、内联事件或动态脚本。
- 页面不读取、上传或保存建筑、测量、仪器、图纸、模型、项目、人员或位置数据。
- 清单结果不构成资料真实性、仪器校准、采光或眩光评价、热工能耗、建筑设计、材料结构、施工消防、法规安全、隐私权利或专业批准。
- 首页、导航、工具、法律页、404 和页脚不放返佣直链。若业务需要转换链接，只在经核实的高意图正文中按站点治理规则单独加入。
- 上线前检查标题、描述、canonical、sitemap、联系渠道、隐私、事实、权利、日期和全部变量。

## 交付检查

1. 五页各一个 `h1`，键盘焦点可见，360px 以上无横向溢出，操作控件至少 44×44px。
2. 正午/暮色主题持久化；编号、摘要、边界和完整报告复制、预设、生成、失效、重置与 404 路由均实际测试。
3. 工具覆盖空值、字段数、格式、边界、NFKC 组合重复、方位/状态白名单、因子等于/严格越界、时刻回退、间隔严格超过、朝向漂移、80 条上限和 XSS 文本化。
4. 运行 JS 语法、仓库验证、严格审计、全库相似度、秘密与占位扫描。
5. 保留独立 CSS/JS，不复用相邻模板的首屏、导航、卡片骨架、动效节奏或工具算法。
