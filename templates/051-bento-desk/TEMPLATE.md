# 051-bento-desk（便当决策桌）

## 适合什么站

返佣情报台 / 内容枢纽站：便当格首页把「转化区 + 特稿 + 栏目 + 文章 + 工具入口」组织成一屏磁贴，天然适合做宽内链枢纽。

## 差异化说明

- 首页采用非对称六列便当格，并增加独立的“决策桌”语义模块，把来源、资格、口径和到账核对放在同一工作台。
- 全套 UI 类名使用 `bd51-` 专属命名空间；不依赖共享 CMS 样式，也不包含其他主题的闲置代码。
- 明暗主题、移动导航、文章进度、复制、精确净手续费对比和 404 检索均由本模板独立实现。

## 转化区

原版 `home_bento` 首页没有邀请码转化卡，本次忠实静态化不再额外插入。需要转化模块时由建站流程在独立转化页配置。

## 页面与文件

index.html / article.html（指南样板：面包屑、目录、表格、FAQ、阅读进度与摘要复制）/ tool.html（净手续费对比器）/ legal.html（披露、免责与披露文本复制）/ 404.html（安全站内检索）/ robots.txt / sitemap.xml；`css/site.css`（全站与首页）+ `css/page.css`（内页）+ `site.js`

## 占位符清单（`%%X%%` 语法）

`%%SITE_NAME%%`、`%%BRAND_EN%%`、`%%SITE_DOMAIN%%`、`%%SITE_DESC%%`、`%%SEO_TITLE%%`、`%%HERO_EYEBROW%%`、`%%HERO_TITLE%%`、`%%HERO_DESCRIPTION%%`、`%%HOME_FEATURED_LABEL%%`、`%%FOOTER_NOTE%%`、`%%AFF_URL%%`、`%%CONTACT_EMAIL%%`、`%%LANG%%`

## 可调项

- 磁贴可增删重排（栏目瓦片/文章卡/工具入口数量不限，grid 自动排布；跨列规则见 css 的 span 设置）
- 建站时首页应扩充为宽内链枢纽：文章卡区按真实文章数量铺开（对标 50+ 内链）
- 配色：改 `:root` 令牌即整站换肤（深色模式记得同步）

## AI 文字接入说明

后续 AI 只替换占位符与可见文字，不需要重新设计 UI。必须保留全部 `bd51-` 类名、元素 `id`、`data-*` 属性、表单 `name`、页内锚点、五个页面文件名及 `css/site.css`、`css/page.css`、`site.js` 的引用关系；这些标记共同维持主题、导航、阅读进度、复制、精确计算和 404 检索。

- 首页的决策桌、文章表格与 FAQ、工具公式、法律披露要使用同一组术语和事实口径。
- 费率、返佣比例、优惠、资格、地区、产品范围、活动时间和到账周期必须来自可追溯来源，并写明核对日期。无法确认的数字应删除或明确标为演示值，不得写成实时承诺。
- 邀请码或推荐链接只有在真实、有效且完成利益披露时才能添加；转化直链须紧邻披露并使用 `rel="sponsored nofollow noopener noreferrer"`。没有授权信息时保持 0 条外链。
- 每页只保留一个 `h1`；不要删除搜索、计算器的标签、帮助文本、错误提示、状态区域或 404 的 `noindex`。

净手续费对比器固定采用以下规则：成交额为 `0.01–1,000,000,000,000` 的普通十进制数且最多 2 位小数；两组手续费率和返佣分成均为 `0–100` 且最多 6 位小数。每组先把手续费四舍五入到分，再把返还四舍五入到分，净成本等于两者之差。若内容要求改变口径，须同步修改 `tool.html`、`site.js`、首页决策桌说明和本文件，并重新覆盖边界测试。

交付前逐页检查标题与描述唯一、本地链接存在、无空锚点；再在桌面和 390px 手机视口验证横向溢出、44px 触控尺寸、明暗主题、菜单焦点、阅读进度、复制、对比器空值/普通值/取整边界/最大值/非法格式/输入后旧结果失效/预设/清空，以及 404 空值、命中、无结果和 HTML 注入文本，最后确认控制台无错误。
