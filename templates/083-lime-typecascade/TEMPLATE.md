# 083-lime-typecascade｜荧光柠檬铅字排演场

## 模板定位

适合新闻专栏、研究长文、编辑方法站和标题驱动的内容品牌。完整 UI 已搭建为黑墨/纸样双主题的铅字瀑布：五页拥有独立头版、长文、校样台、声明页和 404 构图，并包含移动目录、阅读进度、复制反馈、SEO 和无障碍状态。

后续 AI 只需接入站点变量与真实文字，不需要重画导航、标题瀑布、文章排版、校样报告、声明栏或移动端 UI，也不要把页面套回通用卡片博客。

## 文件

- `index.html`：头版与六段错位标题瀑布
- `article.html`：长文排印方法、目录、阅读进度、交接复制
- `tool.html`：标题层级大纲校样台
- `legal.html`：编辑边界、来源、披露、隐私与更正
- `404.html`：本地主题寻路
- `typeset.css`：全部视觉、双主题、响应式和无障碍样式
- `compositor.js`：目录、主题、进度、复制、校样器和寻路交互
- `robots.txt`、`sitemap.xml`：抓取入口

## 全局占位符

- `__LANG__`：页面语言，例如 `zh-CN`
- `__SITE_NAME__`：站点中文名
- `__BRAND_EN__`：短英文品牌名
- `__SITE_DOMAIN__`：域名，不含协议和路径
- `__SITE_TAGLINE__`：头版一句话定位
- `__SITE_DESC__`：站点短描述
- `__CONTACT_EMAIL__`：公开联系邮箱

## AI 文字接入顺序

1. 全局替换七个占位符，并让 canonical、Open Graph、JSON-LD、robots 和 sitemap 使用同一域名。
2. 只替换标题、摘要、正文、日期、版本、示例和真实声明；保留全部 `tc83-` 类名、`data-tc83-*` 属性、ID、文件名与页面结构。
3. 首页六段标题可以换成真实栏目，但保留长短交替和逐级错位；文章章节可换主题，但目录 ID 必须同步。
4. 校样工具可换示例文字，不要改变“层级 | 标题”合同；若改变规则，必须同步重写解析器、界面规则、文档和完整测试。
5. 根据真实业务更新商业披露、数据处理与联系渠道，不得保留不真实的示例承诺。
6. 发布前运行严格审计，并用 1440×1000 与 390×844 复核五页、双主题、移动目录、进度、复制、工具和 404。

## 不要修改

- 不要引入远程字体、图片、框架、统计代码或第三方 CDN。
- 不要把 `typeset.css` 合并进跨站公共样式，不要复用其他模板的类名或 DOM 骨架。
- 不要使用 `innerHTML` 输出标题；所有用户输入继续通过安全文本节点呈现。
- 不要用视觉字号替代正确标题层级，也不要宣称工具能验证 HTML、SEO 排名或辅助技术的完整行为。
- 不要删除空态、错误态、失效态、复制反馈、焦点样式、减少动画和高对比度兼容。

## 发布前检查

- 每页恰好一个可见 `h1`；404 保持 `noindex,follow`。
- 真实页面保持一个 H1，向下层级不跳级，标题脱离正文仍可理解。
- 工具覆盖空值、格式错误、唯一 H1、首项、跳级、重复标题、1/6 层、120/121 行、10000/10001 字符与恶意文本。
- 移动目录打开后聚焦首链，Escape 关闭并回焦；所有交互有效点击区不小于 44×44px。
- 五页无横向溢出、坏链接或控制台错误。
