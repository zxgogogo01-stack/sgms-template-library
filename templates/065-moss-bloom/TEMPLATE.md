# 065-moss-bloom

独立的植物标本馆式编辑模板。首页用压制植物、馆藏标签、非对称标本索引与登记册组织内容；文章页是一份主张解剖专论；工具页在本地定位承诺词、极值词、时效词和带单位数字。所有 UI 使用 `hb65-` 专属命名空间，不依赖公共 CMS 样式、外部字体或外部图片。

## 后续 AI 内容接口

后续 AI 只替换变量和可见文字，不需要重做 UI、标本馆视觉、响应式、主题、移动目录或扫描规则：

1. 全局替换变量；保留 `hb65-` 类名、`data-*` 属性、控件 id 与五个页面文件名。
2. 首页馆藏卡可以整卡增减；保留标本编号、状态和对应站内入口。
3. 文章正文可以替换，但保留来源采集、四项解剖、词类标签和可复制交接记录。
4. 扫描台是发布前的启发式检查，只定位固定词类；不能写成事实核验、合规审查或自动发布工具。
5. 动态输出必须继续使用安全 DOM 节点，不得改用 HTML 字符串拼接。

## 变量

- `%%LANG%%`：页面语言代码，例如 `zh-CN`。
- `%%SITE_NAME%%`：站点名称。
- `%%BRAND_EN%%`：侧栏与页脚品牌名。
- `%%SITE_DOMAIN%%`：不含协议的正式域名。
- `%%SITE_TAGLINE%%`：品牌短句。
- `%%SITE_DESC%%`：首页搜索摘要。
- `%%SEO_TITLE%%`：首页 SEO 标题后半段。
- `%%HERO_EYEBROW%%`：首页主标题上方栏目短句。
- `%%HERO_TITLE%%`：首页唯一一级标题。
- `%%HERO_DESCRIPTION%%`：首页主标题说明。
- `%%HOME_FEATURED_LABEL%%`：首页主索引标签。
- `%%HOME_LINKS_LABEL%%`：首页快捷入口标签。
- `%%HOME_LATEST_LABEL%%`：馆藏登记标签。
- `%%CONTACT_EMAIL%%`：更正联系邮箱，必须换成真实可达地址或联系路径。

## 扫描规则边界

- 输入先统一 CRLF/CR 为换行；总量最多 6000 个 Unicode 字符，最多 80 个非空句子。
- 句子按中文或英文句号、问号、叹号、分号以及换行切分；小数点不会被拆开。
- 扫描在 NFKC 归一文本上进行，显示仍保留原句。
- 承诺词、极值词和时效词使用公开固定词表；数字标签只匹配带百分比、金额、周期、倍数、bps 或基点单位的数值。
- 命中只表示“需要人工复核”，不是事实、法律或合规结论。

## 完整审计

运行 `node tools/audit-template.js templates/065-moss-bloom`、`node tools/validate.js` 和全库逐对相似度检查；再在 1440×1000 与 390×844 验收五页、日藏/夜藏主题、移动目录、文章进度/复制、扫描空态/四类词/全角归一/小数分句/80句/6000字符/上下限/XSS文本化/预设/失效/复制/清空以及 404 安全检索，确保控制台无错误。
