# 047-freeform-folio

## 完整 UI 与内容接口

暖灰出版纸、珊瑚/纯蓝/酸黄色块、三列编辑开场与不等尺度档案。30 个可索引页面、独立 404、3 个兼容入口；十二种内容模块、三类专题、五件本地构图工具、七页治理框架及完整元数据与图像资源。

## 下游 AI 接入

- 只填写站点变量、核实后的文字与文章内容，不重写 UI、交互或工具算法。保留 ff47 类名、data 钩子、表单 name 与锚点。
- 文章首屏有三种结构，章节与 FAQ 数量不同，正文/引用/目录/封面/收尾和相关内容都已预搭。
- 推广区域只是一处 UI 槽位；registrationGuide 是旧检查器兼容字段，不要求生成注册教程。未代写具体站点事实或可发布正文。
- 工具覆盖精确十进制约分、sRGB 对比度、分栏宽度、比例字阶、厘米与像素换算；正常/错误/边界/旧结果失效/重置/复制状态已实现。
- 原有示例案例事实已改为文字变量。文章封面、社交图、图标、技术 SEO 与订阅资源已本地配齐。
- 变量替换要按上下文转义：HTML 文本/属性及 XML 使用对应实体，JSON-LD 使用 JSON 字符串编码；不要直接把引号、标签或未核实 URL 拼入源码。同一内容键在标题、正文和元数据中的文字须保持一致。
- 首页标题分为两行内容接口；品牌、权益脚注和长标题填写后，仍需复跑 360px/390px 首屏与长文本验收。工具输入边界和算法已经实现，不把说明文字的更新变成代码改写。
