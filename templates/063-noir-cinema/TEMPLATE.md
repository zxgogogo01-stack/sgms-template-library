# 063-noir-cinema

独立的黑色电影资料放映馆模板。首页由放映机主视觉、调查长片、三段镜次与片尾资料索引构成；文章页采用场刊与分镜脚本结构；工具页把“镜次标题 | 分:秒”转换为连续的入点、出点与总片长提示单。所有 UI 使用 `nc63-` 专属命名空间，不依赖公共 CMS 样式或外部字体。

## 后续 AI 内容接口

后续 AI 只替换变量和可见文字，不需要重做 UI、放映机视觉、响应式、主题、移动导航或时间码算法：

1. 全局替换变量；保留 `nc63-` 类名、`data-*` 属性、控件 id 与五个页面文件名。
2. 首页调查镜次可改写文字；增减镜次时复制完整 `li`，并同步可见时间码。
3. 文章正文可替换，但保留四段场景 id、证据场记板与可复制交接提示。
4. 工具每次接受 1–60 个非空镜次；格式固定为 `标题 | 分:秒`，标题最多 80 个 Unicode 字符。
5. 提示单只用于内容制作与复核排程，不代表任何平台的结算时间或业务承诺。

## 变量

- `%%LANG%%`：页面语言代码，例如 `zh-CN`。
- `%%SITE_NAME%%`：站点名称。
- `%%BRAND_EN%%`：页眉与页脚品牌名。
- `%%SITE_DOMAIN%%`：不含协议的正式域名。
- `%%SITE_TAGLINE%%`：品牌短句。
- `%%SITE_DESC%%`：首页搜索摘要。
- `%%SEO_TITLE%%`：首页 SEO 标题后半段。
- `%%HERO_EYEBROW%%`：首页主标题上方栏目短句。
- `%%HERO_TITLE%%`：首页唯一一级标题。
- `%%HERO_DESCRIPTION%%`：首页主标题说明。
- `%%HOME_FEATURED_LABEL%%`：首页放映条标签。
- `%%HOME_LINKS_LABEL%%`：资料馆索引标签。
- `%%HOME_LATEST_LABEL%%`：调查镜次标签。
- `%%CONTACT_EMAIL%%`：更正联系邮箱，必须换成真实可达地址或联系路径。

## 时间码算法

- 输入先做 NFKC 归一化并逐行修剪；空行忽略，总输入最多 6000 个 Unicode 字符。
- 每行必须且只能有一个 `|`；标题为 1–80 个字符，时长使用 `0:01` 到 `999:59` 的严格格式，秒位必须两位且不超过 59。
- 最多 60 个镜次，总片长不得超过 12 小时。时间码统一输出为 `HH:MM:SS`，每一镜的出点等于下一镜入点。
- 输出使用安全 DOM 节点，不得改为 HTML 字符串拼接。
