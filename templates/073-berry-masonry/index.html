01 / METHOD

先建立阅读顺序，再追求错落感

屏幕上的位置可以变化，但标题层级、DOM 顺序和键盘顺序应保持一致。

7 MIN READ
02 / TOOL

用最短列规则预估卡片落点

输入标题和预估高度，比较各列最终负载。

LOCAL TOOL
03 / EDIT

同一张卡只保留一个主要入口

多个同权重按钮会让瀑布墙变成控制面板。次要信息可以留在详情页。

EDITOR NOTE
04 / ACCESS

颜色之外，还要有文字标签

状态、类别与风险不能只靠色相表达。

VISIBLE LABEL
05 / SOURCE

长卡片不是结论更重要，而是证据更完整

卡片高度受摘要长度影响。编辑时不要为了对齐删除关键限制，也不要为了占满空位制造无价值段落。

KEEP CONTEXT
