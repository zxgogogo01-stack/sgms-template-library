# 038 安静终端

一套默认深色、等宽字体、无圆角的高端运行状态模板。视觉重点是克制的信号色、紧凑但清晰的数据层级，以及能被复核的服务矩阵和事件记录。

## 页面

- `index.html`：运行看板，包含状态筛选、30 天摘要、六项服务矩阵、可展开事件流与复制运行摘要。
- `article.html`：采集说明，覆盖来源、统计窗口、状态判定、数据缺口与引用格式。
- `tool.html`：本地可用率分析台，可计算百分比、每日平均停机和 99.9% 目标剩余预算，包含示例、错误提示、清空与复制结果。
- `legal.html`：数据边界，说明数据性质、准确性、延迟、统计窗口、引用与修订政策。
- `404.html`：延续命令行语气的缺失记录页。

## 文件

- `site.css`：共享视觉系统、响应式布局、浅色模式、键盘焦点与减少动态效果适配。
- `app.js`：状态筛选、复制反馈与可用率计算；不依赖第三方库。
- `robots.txt`、`sitemap.xml`：基础搜索引擎配置。

## 替换项

- `__SITE_NAME__`：站点名称
- `__SITE_DOMAIN__`：站点域名
- `__SITE_TAGLINE__`：首页短说明
- `__SITE_DESC__`：站点描述
- `__CONTACT_EMAIL__`：联系邮箱
- `__LANG__`：页面语言，如 `zh-CN`

## 可选调整

- 首页服务条目使用 `data-service` 与 `data-status`，支持 `operational`、`degraded`、`maintenance` 三种筛选状态。
- 事件记录由原生 `details` 组成，可按需要复制、删除或默认展开。
- 若不需要分析工具，可删除导航中的“可用率”入口与 `tool.html`，其余页面不受影响。
- 颜色、内容宽度和字体变量位于 `site.css` 顶部。建议保留默认深色、直角边框和单一荧光信号色，以维持模板识别度。

## 隐私与说明

模板没有账号、邀请制、外部脚本、字体或追踪服务。分析数据只在当前浏览器中计算，不会保存或上传。首页数值和事件均为结构示例，上线前必须替换为有权使用且已核验的数据源。
