# 157 Grand Key Cabinet

一套可直接换字使用的高端礼宾钥匙柜模板。品牌、全屏目录、首页、文章、本地工具、守则、404、robots、sitemap 与独立静态资源均已搭好；后续 AI 只替换变量和正文，不需要在网站模板 UI 上重新设计或消耗额外 token。

## 替换变量

- `{{LANG}}`：页面语言代码，例如 `zh-Hans`
- `{{SITE_NAME}}`：站点名称
- `{{SITE_DOMAIN}}`：域名，不含协议和路径
- `{{SITE_DESC}}`：站点简介
- `{{HOUSE_MARK}}`：2–8 字符品牌短标或字母标
- `{{EDITION_LABEL}}`：资料期次、栏目或专题标签
- `{{HERO_NOTE}}`：首屏陈述，建议 38–90 个中文字符
- `{{CABINET_CODE}}`：首页可复制的柜号；它不是邀请码，也不应自动变成外链
- `{{ARTICLE_META}}`：文章版本、期次或更新标签
- `{{CONTACT_CHANNEL}}`：联系渠道展示文字

全仓搜索 `{{` 即可定位变量。替换时保持 HTML 转义，不写入未经核实的场所、住客、员工、房间、锁具、权限、事件或结论。

## 完整页面

- `index.html`：礼宾门厅、CSS 黄铜钥匙与艺术装饰柜、悬浮柜牌和三封入口信。
- `article.html`：六封完整礼宾信、纵向信封章节、阅读进度与摘要复制。
- `tool.html`：本地钥匙流转审计台；除非业务规则确实改变，不要改选择器、字段或状态机。
- `legal.html`：六条礼宾守则，覆盖资料、保管、安保、设施消防、隐私劳动和发布权利。
- `404.html`：独立缺钥匙视觉与本地关键词路由。
- `robots.txt` / `sitemap.xml`：上线前替换域名，确认四个 canonical 可索引页面全部进入 sitemap。

## 工具固定格式

每行：`钥匙号 | 序号 | 去向 | 借出HH:MM | 归还HH:MM | 状态`

- 2–80 条非空记录，总输入不超过 8000 个 Unicode 字符。
- 钥匙号归一后为 2–20 个 Unicode 字符；先拒绝控制/格式字符，再做 NFKC、大小写与重复空白归一。钥匙号可在不同序号重复。
- 同一钥匙号与序号的组合归一后必须全局唯一；序号为 1–9999 的无符号普通十进制整数。
- 去向只能是：`客房`、`前台`、`工程`、`安保`、`仓储`、`其他`。
- 借出与归还必须为 `00:00–23:59` 的两位 `HH:MM`，归还严格晚于借出；模板不自动处理跨日。
- 状态只能是：`草记`、`核对`、`封存`。
- 用户输入单次时长上限 1–1440 分钟、空置间隔上限 0–1440 分钟；拒绝符号、小数、指数和多位前导零。
- 每笔占用分钟为归还减借出；严格超过单次上限才提示，等于上限通过。
- 每把钥匙按序号排序后检查：最小序号从 1 开始、相邻序号连续、下一笔借出不得早于上一笔归还；相等视为无空档衔接。
- 无冲突时计算相邻空档，严格超过用户上限才提示，等于上限通过。缺号、冲突和空档只代表清单需复核，不自动证明遗失或违规。
- 每条 `草记` 各形成一项状态提示。
- 结果状态为 `KEY CLEAR`、`CUSTODY FLAGS N`、`SEQUENCE FLAGS N`、`STATUS FLAGS N` 或 `REVIEW N`。
- 界面最多显示前 40 条提示和前 40 条流转，完整复制保留全部记录与提示；任一输入变化都会使旧报告失效。

## 视觉系统

- 原创礼宾钥匙柜语言：深梅黑、酒红、暖奶油、黄铜、玉绿和旧玫瑰。
- 常规页头只有品牌、期次和目录按钮；目录以全屏四扇编号门展开，和相邻模板的常驻顶部四格导航、右侧导航或固定侧栏不同。
- 首页以杂志式门厅文案、放大黄铜钥匙、艺术装饰柜线和不对称行李牌组成首屏；入口是三列信件注册簿。
- 文章使用纵向信封编号带，工具使用双列钥匙孔柜，守则使用横向编号门牌；没有复用相邻模板的日光剖面。
- 日班/夜班主题分别调校漆面、纸面、黄铜和阴影，不做机械反色。
- 全部钥匙、柜门、拱线、号码与 404 视觉均由 CSS 绘制，无外部字体、图片、图标、CDN 或跟踪脚本。
- 类名 `hq157-` 与 `data-hq157-*` 是独立命名空间，不要换成其他模板类名。

## 安全与发布

- 用户输入只通过 `textContent` 写回 DOM；预览样式只使用去向白名单映射。不要改成 `innerHTML`、`insertAdjacentHTML`、内联事件或动态脚本。
- 页面不读取、上传或保存住客、员工、房号、钥匙、门禁、位置、日期、时间或事件资料。
- 清单结果不构成身份验证、授权、真实交接、遗失判断、门禁安保、消防设施、隐私劳动、保险事件或法律批准。
- 不公开可帮助绕过实体安防的编号映射、门锁细节、备用钥匙位置或人员行踪。
- 首页、导航、工具、法律页、404 和页脚不放返佣直链。若业务需要转换链接，只在经核实的高意图正文中按站点治理规则单独加入。
- 上线前检查标题、描述、canonical、sitemap、联系渠道、隐私、事实、权利、日期和全部变量。

## 交付检查

1. 五页各一个 `h1`，全屏目录支持打开、关闭与 Escape，键盘焦点可见，360px 以上无横向溢出，操作控件至少 44×44px。
2. 日班/夜班主题持久化；柜号、文章摘要、守则和完整报告复制、预设、生成、失效、重置与 404 路由均实际测试。
3. 工具覆盖空值、字段数、格式、边界、NFKC 组合重复、去向/状态白名单、同日时刻、时长等于/严格超过、序号起点/缺口、交接相撞、空档等于/严格超过、80 条上限和 XSS 文本化。
4. 运行 JS 语法、仓库验证、严格审计、全库相似度、秘密与占位扫描。
5. 保留独立 CSS/JS，不复用相邻模板的首屏、导航、卡片骨架、动效节奏或工具算法。
