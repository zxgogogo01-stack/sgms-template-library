    PASS 01 / SOURCE

    源文件先于所有漂亮印痕

    文件名、版本、页面、字体、图像、专色、出血、裁切与输出设置都可能变化。页面演示不能证明某个真实文件已被核对，也不能替项目负责人补全缺失信息。

    如果版本不清楚，后面的精确只是精确地重复错误。

    公开案例、图像、字体、商标或客户信息前，还应逐项确认许可、隐私、保密与发布范围。

    PASS 02 / VECTOR

    X 与 Y 是输入，不是设备诊断

    偏移尺把用户输入的小数转换为百分之一毫米整数，再以 X²+Y² 与容差²进行精确比较。它不读取相机、扫描仪、印刷机或测量仪。

    显示值

    径向偏移以“约”显示到两位小数；是否超差只由未舍入的整数平方比较决定。

    PASS 03 / TOLERANCE

    容差必须来自项目，不由页面推荐

    纸张、网点、印刷方式、设备、图像内容、观察距离和质量制度都可能影响真实容差。工具要求用户明确输入 0.01–99.99 mm，不提供默认行业标准。

    • 刚好落在用户容差圆上的记录视为未超差。
    • 任何输入变化都会使旧报告立即失效。
    • 文档状态与几何判断分别列示。
    PASS 04 / OBSERVE

    屏幕、纸面与现场光线不是同一件事

    颜色空间、显示器、照明、油墨、纸张、干燥、涂层与环境都会改变观察结果。CSS 叠色只是一种视觉语言，不是色彩证明或可生产色样。

    可见的色差，不等于已知道原因；看不见，也不等于没有风险。
    PASS 05 / RELEASE

    放行要有人、有版本、有时间

    交接可记录文件版本、测量方法、坐标、用户容差、异常、状态、确认人与日期。真实字段与批准流程由项目制度决定。

    边界

    本地报告不构成签样、调机、返工、报价、采购、生产、验收或交付决定。
