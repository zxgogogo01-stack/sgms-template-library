# 031-tabular-times

## 模板定位

高端城市公共数据晨报／指标新闻站。把“表格时报”从普通后台表格升级为有编辑判断的数据出版物，适合城市观察、公共服务简报、行业监测、运营日报和研究摘要。

## 视觉与结构

- 以新闻纸、报表网格、等宽数字和编辑蓝／警示橙构成清晰的时报身份
- 坚持“零 class”属性选择器体系，所有页面通过语义标签、ID 与 `data-*` 属性组织样式
- 首页包含四项晨间快照、四项核心指标、可搜索／分类／排序的指标表、空结果恢复、头条与快讯
- `article.html` 是完整数据新闻文章，包含编辑结论、对照表、异常解释与方法说明
- `tool.html` 提供可用的数据摘要计算器，支持样例、严格输入校验、错误焦点、样本标准差、复制与清空
- `legal.html` 说明数据来源、指标计算、质量控制、隐私、访问码合规与更正机制
- `404.html` 延续表格查询语义，给出错误诊断和明确返回路径，不是简单占位页
- 完整覆盖桌面、手机、自动深色模式、键盘焦点与减少动态偏好

## 可替换占位符

`__SITE_NAME__`、`__SITE_DOMAIN__`、`__SITE_TAGLINE__`、`__SITE_DESC__`、`__CONTACT_EMAIL__`、`__INVITE_CODE__`、`__COMPLIANCE_NOTE__`、`__LANG__`

## 可编辑区域

- 首页指标行可增删；`data-kind` 使用 `mobility`、`environment`、`service`，并与筛选按钮的 `data-filter` 对应
- `data-change` 必须是可排序的数字；展示文本可以使用百分比或百分点
- 指标 `meter` 的上下限应按真实业务口径调整，不要为了视觉统一虚构 0–100 范围
- 文章中的数字、时间窗口和结论必须与首页对应，避免同一指标在不同页面冲突
- 访问码仅是合规模板位；没有真实受限资料时，应删除整块入口及相关脚本
- 若移除页面，请同步更新所有导航、`sitemap.xml` 和本说明

## 交互说明

- 首页支持本地搜索、分类筛选、变化排序和一键清除空结果
- 统计工具接受空格、逗号或换行分隔的 2–500 个有限数值
- 复制访问码与统计摘要均提供无障碍状态反馈，并包含剪贴板不可用时的降级提示
- 所有处理在浏览器本地完成，不依赖第三方接口

## 后续 AI 的文字接入顺序

1. 先一次性替换八个全局变量/占位符，再逐页接入经核验的城市指标、数据窗口、来源、编辑结论、文章、方法与联系信息。
2. 只改文字、数字、链接、日期和表格行；保留零 class 的 `data-*` 选择器体系、页面结构、响应式断点、表单 ID、ARIA 关系与现成交互。
3. 首页筛选/搜索/排序/空态、访问码、完整数据文章、统计摘要工具、方法页和 404 已搭好。后续 AI 不应重做 UI；增删指标时只复制语义表格行并同步 `data-kind`、`data-change` 与 meter 口径。
4. 内容接入后核对 title、description、canonical、数字与文章是否一致、来源和免责声明，并实测筛选、搜索、双向排序、恢复、访问码、统计空值/非法项/样本上下限/极大数/输入失效/样例/清空/复制。
5. 最后运行 `node tools/audit-template.js templates/031-tabular-times`，并与库内其余模板逐对执行相似度检查。

完整视觉、桌面/移动布局、深浅主题和交互框架均已完成；后续 AI 应把 token 用在数据、事实、来源与编辑判断上，不在模板 UI 上重复消耗。
