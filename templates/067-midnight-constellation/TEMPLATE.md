# 067-midnight-constellation

独立的浅色航海星图模板。首页以黄铜星盘、四星区和航图登记组织内容；文章页讲解标签编目与信息架构；工具页统计每行标签的共现连接和孤立节点。所有 UI 使用 `cn67-` 专属命名空间，不依赖公共 CMS 样式、外部字体或图片。

## 后续 AI 内容接口

后续 AI 只替换变量和可见文字，不需要重做 UI、星盘视觉、响应式、主题、移动菜单或共现统计器：

1. 全局替换变量；保留 `cn67-` 类名、`data-*` 属性、控件 id 与五个页面文件名。
2. 首页星区和登记项可整项增减；每项保持明确的入口或边界职责。
3. 文章正文可替换，但保留入口、连接、孤立项解释、人工决定和可复制交接。
4. 工具输出只描述输入标签结构，不得写成 SEO、因果、内容质量或自动栏目决策。
5. 动态列表必须继续使用安全 DOM 节点，不得改为 HTML 字符串拼接。

## 变量

`%%LANG%%`、`%%SITE_NAME%%`、`%%BRAND_EN%%`、`%%SITE_DOMAIN%%`、`%%SITE_TAGLINE%%`、`%%SITE_DESC%%`、`%%SEO_TITLE%%`、`%%HERO_EYEBROW%%`、`%%HERO_TITLE%%`、`%%HERO_DESCRIPTION%%`、`%%HOME_FEATURED_LABEL%%`、`%%HOME_LINKS_LABEL%%`、`%%HOME_LATEST_LABEL%%`、`%%CONTACT_EMAIL%%`。

## 共现统计边界

- 总输入最多 8000 个 Unicode 字符、100 个非空记录。
- 每行最多 12 个非空标签；单个标签最多 30 个 Unicode 字符；全局最多 80 个唯一标签。
- 标签先做 NFKC 归一、修剪空白并按大小写不敏感键去重；显示名保留首次出现形式。
- 同一行两两组合形成连接；一行只有一个标签时，该标签可能成为孤立节点。前 20 组按次数降序、标签名稳定排序。
- 连接只表示共现，不代表因果、相关性、质量或搜索价值。
