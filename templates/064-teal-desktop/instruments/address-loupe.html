Guide · 使用与边界
作用范围
离线查看地址来源、路径、查询参数数量与片段。不发起网络请求，不检查网站信誉、DNS 或响应状态。
输入方式
每行完整 HTTP 或 HTTPS 地址，不含用户名与密码。请勿粘贴会话令牌或其他敏感查询值。
计算方法
使用浏览器 URL 解析规则：主机可能转为小写或 ASCII，默认端口省略，路径按标准规则规范化。
如何读报告
查询参数按 URLSearchParams 条目数统计，重名参数分别计数。报告不展示查询值；片段保留编码形式。
限制与错误
最多 60 个地址，每个 2048 字符。空白、反斜线、无效百分号编码、不完整 Unicode 和地址凭据会被拒绝。合法结构不表示安全或可访问。
重置与复制
仅在当前页面处理。复制报告不会包含查询值；输入变动使报告失效；离开页面后输入不保存。
