# 064-teal-desktop

独立的青绿色研究桌面模板。首页用纸面、放大镜、研究笔记、四类资料托盘和登记册组织内容；文章页是带来源字段与未决问题的核对笔记；工具页检查粘贴表格的分隔符、逻辑行列、列数不齐和空单元格。所有 UI 使用 `td64-` 专属命名空间，不依赖公共 CMS 样式或外部字体。

## 后续 AI 内容接口

后续 AI 只替换变量和可见文字，不需要重做 UI、研究桌视觉、响应式、主题、移动导航或表格解析器：

1. 全局替换变量；保留 `td64-` 类名、`data-*` 属性、控件 id 与五个页面文件名。
2. 首页登记册可增减完整行；必须保留 `role="row"` 与每个单元的 `role`。
3. 文章正文可替换，但保留来源护照、四段核对流程、未决问题和可复制交接记录。
4. 表格检查器接受逗号、Tab、分号或竖线分隔；支持双引号字段与 `""` 转义。
5. 检查结果只描述粘贴文本的形状，不判断资料事实是否正确，也不会上传输入。

## 变量

- `%%LANG%%`：页面语言代码，例如 `zh-CN`。
- `%%SITE_NAME%%`：站点名称。
- `%%BRAND_EN%%`：页眉与页脚品牌名。
- `%%SITE_DOMAIN%%`：不含协议的正式域名。
- `%%SITE_TAGLINE%%`：品牌短句。
- `%%SITE_DESC%%`：首页搜索摘要。
- `%%SEO_TITLE%%`：首页 SEO 标题后半段。
- `%%HERO_EYEBROW%%`：首页主标题上方栏目短句。
- `%%HERO_TITLE%%`：首页唯一一级标题。
- `%%HERO_DESCRIPTION%%`：首页主标题说明。
- `%%HOME_FEATURED_LABEL%%`：首页状态条标签。
- `%%HOME_LINKS_LABEL%%`：首页快捷入口标签。
- `%%HOME_LATEST_LABEL%%`：首页登记册与笔记标签。
- `%%CONTACT_EMAIL%%`：更正联系邮箱，必须换成真实可达地址或联系路径。

## 表格解析边界

- 输入先统一 CRLF/CR 为换行；总量最多 20000 个 Unicode 字符。
- 自动模式在引号外统计逗号、Tab、分号和竖线，选择出现次数最多者；相同次数按 Tab、逗号、分号、竖线优先。
- 双引号字段只能从字段开头进入；字段内 `""` 表示一个引号。未闭合引号或闭合引号后的非法字符会拒绝解析。
- 忽略完全空白的逻辑行；最多 200 行、20 列。预览最多显示前 10 行与前 10 列，超长单元格安全截断为 120 个字符。
- 输出使用安全 DOM 节点，不得改为 HTML 字符串拼接。

## 完整审计

运行 `node tools/audit-template.js templates/064-teal-desktop`、`node tools/validate.js` 和全库逐对相似度检查；再在 1440×1000 与 390×844 验收五页、主题、移动导航、文章进度/复制、工具空态/自动和四种分隔符/引号与转义/嵌入换行/未闭合引号/非法尾字符/单列/空单元/列数不齐/20列/200行/上下限/失效/复制/清空以及 404 安全检索，确保控制台无错误。
