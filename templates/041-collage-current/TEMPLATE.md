# 041-collage-current

## 模板定位

高端独立城市刊物与非对称剪报墙。保留原模板的强对比色块、瑞士网格与纸张拼贴气质，并扩展为可直接填入经核实文字的完整 workflow-ready v2 网站框架。

## 页面职责

- 30 个可索引角色：1 个首页、1 个剪报索引、12 个文章槽位、3 面主题墙、1 个工具索引、5 个真工具与 7 个治理页面。
- `article.html` 与 `tool.html` 为旧入口兼容索引，均为 `noindex,follow`。
- `stories/editorial-access-note.html` 只是差异化文章 UI 与文字槽位，不含注册步骤、平台事实或教程正文；仅保留一个受控推广链接占位。
- 下游 AI 只替换变量、经核实的站点文字与文章内容，不改 `cc41-` 类名、页面角色、`data-*` 钩子、工具算法或视觉资产。

## 五张本地工作台

1. 标题行平衡尺：比较多行标题字符重量与允许行差。
2. 来源覆盖核对板：逐项检查判断与来源的配对完整度。
3. 墙面跨度编排器：按主卡位置与密度生成卡片跨度。
4. 图注容量检验器：按字符上限标记图注余量与超限。
5. 修订顺序检查器：验证时间格式、回退和重复时标。

每件工具都具备正常、错误、边界、输入变化失效旧结果、重置、复制和默认折叠的五段 Guide。所有计算只在当前浏览器执行。
