# 135 Herbarium Vault

以植物标本页、馆藏抽屉、竖向索引栏、纸张压痕和朱红标记为视觉语言的五页原创静态模板。CSS 植物标本首屏、五段采集札记、种子批次观察工具、抽屉式责任页和未入藏 404 均已完成；后续 AI 只需替换变量、可见文字和示例数据，不需要重新搭建 UI、交互或响应式框架。

## 变量

- `{{LANG}}`：HTML 语言标签，如 `zh-CN`。
- `{{SITE_NAME}}`：站点名，建议 2–12 个汉字或 4–18 个拉丁字符。
- `{{BRAND_EN}}`：英文植物档案刊头，建议 4–16 个字符。
- `{{SITE_TAGLINE}}`：首屏短标签，建议 10–30 个字符。
- `{{HERO_DESCRIPTION}}`：首屏简介，建议 35–90 个字符。
- `{{ARTICLE_META}}`：文章日期、作者或版本信息，建议 10–35 个字符。
- `{{SITE_DESC}}`：页脚摘要，建议 20–60 个字符。
- `{{SITE_DOMAIN}}`：不含协议的域名。
- `{{CONTACT_CHANNEL}}`：公开联系渠道或联系页路径，不要放私人凭据。

## 页面与完整框架

- `index.html`：竖向馆藏索引、CSS 压制植物标本、右侧抽屉章节、采集/压制/鉴定/入藏叙事和柜门式工具入口。
- `article.html`：五段植物采集札记、页边目录、阅读进度、标本标签、字段卡和摘要复制。
- `tool.html`：种子批次加权总发芽比例、小样本、异常数与归档状态审计器。
- `legal.html`：六只互斥展开的采集、鉴定、标本、种子、生态与权利责任抽屉。
- `404.html`：最多 80 个 Unicode 字符的本地馆藏路由，用户输入只通过 `textContent` 反馈。

工具格式为 `批次 | 播种数 | 发芽数 | 异常数 | 状态`：接受 2–120 条非空记录，总长最多 6000 个 Unicode 字符。批次名执行 NFKC、去除首尾空格、合并内部空格并忽略大小写后必须全局唯一，长度为 2–24 个 Unicode 字符，拒绝控制字符和格式字符；完全重复记录与重复批次均会被拒绝。播种数必须是 1–100000 的普通十进制整数，发芽数与异常数必须是 0–100000 的普通十进制整数，均不接受符号和前导零；发芽数与异常数之和不能超过播种数。状态只能为“观察 / 复核 / 封存”。

总发芽比例使用全部发芽数除以全部播种数，而不是对各批次百分比作简单平均；工具用 `BigInt` 计算百分比并四舍五入到两位小数。播种数低于 20 和异常数大于 0 分别产生观察提示，未封存状态另行统计。提示只是交接线索，不代表实验失败或生物结论。界面最多显示前 40 条提示和前 40 个批次，复制完整报告会保留全部记录。

## 后续 AI 内容接入顺序

1. 全局替换上述变量，再重写可见标题、段落、示例数据和项目政策；不要删除既有 `data-hb135-*` 属性。
2. 保留五页、竖向索引、CSS 标本页、右侧章节抽屉、文章结构、工具输出、互斥责任柜和移动端头部，不需要为新文案重做 UI。
3. 用真实项目的批次规则、观察口径、实验条件、许可、鉴定、保管、种子、生态与权利政策替换示例。
4. 检查 title、description、canonical、Open Graph、robots 与 sitemap 的域名和路径。
5. 在 1440×1000 与 390×844 下逐页测试夜间柜藏持久化、阅读进度、工具边界、加权比例、完整复制、重置、互斥抽屉和 404 路由。
