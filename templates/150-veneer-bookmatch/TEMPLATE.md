# 150 Veneer Bookmatch

以木皮镜拼、黄铜接缝、工坊裁片和批次签为视觉语言的五页原创静态模板。首页、五则镜拼工坊记、本地木皮试拼工具、六张责任签和接缝检索 404 均已完成；后续 AI 只需替换变量、可见文字和演示记录，不需要重新搭建 UI、交互或响应式框架。

设计只提炼高端家具与建筑作品集中“温暖材料色、沉浸式材质首屏、编辑留白、克制排版与顺滑微交互”的公开方法。品牌、文案、CSS 木纹、镜拼构图、页面骨架、交互与算法均为本模板原创重建；不得照搬任何参考站的品牌、图片、文案、受限素材或实现代码。

## 变量

- `{{LANG}}`：HTML 语言标签，如 `zh-CN`。
- `{{SITE_NAME}}`：站点名，建议 2–12 个汉字或 4–18 个拉丁字符。
- `{{ATELIER_MARK}}`：工坊或工作室短标，建议 4–16 个字符。
- `{{SITE_TAGLINE}}`：首屏短句，建议 10–30 个字符。
- `{{HERO_DESCRIPTION}}`：首屏简介，建议 35–90 个字符。
- `{{FEATURE_VENEER}}`：纯演示木皮或镜拼册名，不得冒充真实树种、等级、来源或品质结论。
- `{{BATCH_CODE}}`：可复制的内部批次编号，不得冒充材料认证、供应链凭据、质检或结构审批。
- `{{ARTICLE_META}}`：文章日期、作者或版本信息，建议 10–35 个字符。
- `{{SITE_DESC}}`：页脚摘要，建议 20–60 个字符。
- `{{SITE_DOMAIN}}`：不含协议的域名。
- `{{CONTACT_CHANNEL}}`：公开联系渠道或联系页路径，不要放私人凭据。

## 页面与完整框架

- `index.html`：顶部工坊导航、全屏 CSS 木皮镜拼、黄铜接缝、五步登记条、三段工序、中央接缝、三个抽屉与批次签。
- `article.html`：连续、朝向、宽差、尾片与交接五记，含阅读进度、粘性章节、边注、清单与摘要复制。
- `tool.html`：叶片编号、整数毫米、正/反纹、用户宽差容差、相邻配对、通过对、最大宽差、尾片和状态审计。
- `legal.html`：六张互斥责任签，覆盖材料来源、含水环境、裁切拼接、结构耐久、健康安全和权利发布。
- `404.html`：最多 80 个 Unicode 字符的本地接缝路由；用户输入只通过 `textContent` 反馈。
- `static/veneer-bookmatch.css`：独立命名空间、日光/工坊灯双主题、纯 CSS 木纹镜拼、桌面与移动端完整布局。
- `static/veneer-bookmatch.js`：主题持久化、阅读进度、复制、互斥责任签、404 路由和本地镜拼审计算法。

## 工具输入与算法

工具格式为 `叶片号 | 宽度mm | 朝向 | 状态`：接受 3–60 条非空记录，总长最多 6000 个 Unicode 字符。叶片号执行 NFKC、去除首尾空格、合并内部空格并忽略大小写后必须全局唯一；原始长度须为 2–20 个 Unicode 字符，拒绝控制字符和格式字符。

宽度接受 1–2000 的普通十进制整数毫米，不接受正负号、小数、指数或前导零。朝向仅接受“正纹”“反纹”，状态仅接受“待裁”“试拼”“定稿”。配对宽差容差单独接受 0–100 的普通十进制整数毫米，不接受正负号、小数、指数或前导零。

工具严格按输入顺序，将第 1–2 片、第 3–4 片依次组成完整对。完整对的两片朝向相同，生成一项朝向提示；宽差为两个整数毫米的绝对差，严格大于用户容差时生成一项宽差提示，等于容差时不提示。输入总数为奇数时，最后一片生成一项尾片提示，工具不会重排或借用其他叶片。每条非“定稿”记录生成一项状态提示。

内部通过对须同时满足一正一反且宽差小于等于容差。总宽为全部宽度整数之和；最大宽差取全部完整对的宽差最大值。这里不扣除锯缝、修边、拼缝、加工余量或材料变化。

同时存在木皮提示与状态提示时显示 `REVIEW N`，只有朝向/宽差/尾片提示时显示 `VENEER FLAGS N`，只有状态提示时显示 `STATUS FLAGS N`，均无提示时显示 `MATCH CLEAR`。界面最多显示前 40 项提示；最多 60 片的镜拼预览和完整复制交接保留全部记录。

四组预设用于审计：`平衡镜拼` 无提示；`同向叶片` 验证朝向提示；`容差边界` 验证等于容差不提示、严格大于才提示；`综合复核` 同时生成朝向、宽差、尾片与状态提示。

## 后续 AI 内容接入顺序

1. 全局替换上述变量，再重写可见标题、段落、演示记录和项目政策；不要删除既有 `data-ve150-*` 属性。
2. 保留五页、顶部导航、CSS 木皮镜拼首屏、文章五记、试拼工具、互斥责任签和响应式框架，不需要为新文案重做 UI。
3. 用经过确认的叶片编号、整数宽度、朝向、容差与状态替换示例；不要让后续 AI 从照片、木纹名称或屏幕预览猜测真实材料参数。
4. 检查 title、description、canonical、Open Graph、robots 与 sitemap 的域名和路径。
5. 在 1440×1000 与 390×844 下逐页测试日光/工坊灯主题持久化、阅读进度、成对顺序、同向、容差等值、奇数尾片、60 片上限、完整复制、重置、互斥责任签和 404 路由。
