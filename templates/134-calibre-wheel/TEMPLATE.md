# 134 Calibre Wheel

以高级制表轮系、深海军蓝工作台、香槟金属、宝石轴承和圆形章节表盘为视觉语言的五页原创静态模板。CSS 机芯首屏、五段机芯札记、精确轮系工具、铭牌式责任边界和缺齿 404 均已完成；后续 AI 只需替换变量、可见文字和项目示例，不需要重新搭建 UI、交互或响应式框架。

## 变量

- `{{LANG}}`：HTML 语言标签，如 `zh-CN`。
- `{{SITE_NAME}}`：站点名，建议 2–12 个汉字或 4–18 个拉丁字符。
- `{{BRAND_EN}}`：英文制表档案刊头，建议 4–16 个字符。
- `{{SITE_TAGLINE}}`：首屏短标签，建议 10–30 个字符。
- `{{HERO_DESCRIPTION}}`：首屏简介，建议 35–90 个字符。
- `{{ARTICLE_META}}`：文章日期、作者或版本信息，建议 10–35 个字符。
- `{{SITE_DESC}}`：页脚摘要，建议 20–60 个字符。
- `{{SITE_DOMAIN}}`：不含协议的域名。
- `{{CONTACT_CHANNEL}}`：公开联系渠道或联系页路径，不要放私人凭据。

## 页面与完整框架

- `index.html`：大型 CSS 轮系机芯、四点圆形章节导航、动力/轮系/擒纵/上链叙事与表冠式工具入口。
- `article.html`：五段机芯观察札记、粘性目录、阅读进度、CSS 爆炸轮系图和摘要复制。
- `tool.html`：精确总传动比、输出旋向、齿数公因数接触循环和文档状态审计器。
- `legal.html`：六项互斥展开的文字计算、几何、材料、装配、计时与权利边界。
- `404.html`：最多 80 个 Unicode 字符的本地栏目路由，输入只用 `textContent` 反馈。

工具格式为 `级位 | 主动齿 | 从动齿 | 啮合 | 状态`：接受 2–120 条非空记录，总长最多 6000 个 Unicode 字符。级位名执行 NFKC、去除首尾空格、合并内部空格并忽略大小写后必须全局唯一，长度为 2–24 个 Unicode 字符，拒绝控制字符与格式字符；完全重复记录和重复级位都会被拒绝。主动齿与从动齿必须是 6–240 的普通十进制整数，不接受符号和前导零；啮合只能为“外啮合 / 内啮合”，状态只能为“草图 / 复核 / 锁定”。

每一级速度因子为“主动齿 ÷ 从动齿”。工具以 `BigInt` 相乘，并在每次相乘后用最大公约数约分，因而总传动比保留精确整数分数；外啮合每次翻转旋向，内啮合保持旋向。当齿数最大公约数大于 1 时，工具给出重复接触组提示；这是机械文档线索，不是设计缺陷或故障判断。未锁定状态另行统计。界面最多显示前 40 条提示和前 40 级，复制完整报告保留全部记录。

## 后续 AI 内容接入顺序

1. 全局替换上述变量，再重写可见标题、段落、示例数据和项目政策；不要删除既有 `data-cw134-*` 属性。
2. 保留五页、CSS 轮系机芯、圆形章节导航、文章层级、工具输入输出、互斥责任铭牌与移动端结构，不需要为新文案重做 UI。
3. 用真实项目的级位命名、齿数、啮合方式、状态规则、几何验证、材料、润滑、装配、计时、制造、安全与权利政策替换示例。
4. 检查 title、description、canonical、Open Graph、robots 与 sitemap 的域名和路径。
5. 在 1440×1000 与 390×844 下逐页测试检修光持久化、阅读进度、工具边界、精确分数、完整复制、重置、互斥折叠和 404 路由。
