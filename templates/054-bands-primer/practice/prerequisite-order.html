Guide · 输入、方法与使用边界
输入格式
每行使用 A: B,C 的格式；冒号右侧为空表示无前置。最多 20 行、5000 个标准化后的 UTF-16 字符，不留空行。标识为字母开头的 1–16 位字母、数字、下划线或连字符。
整理方法
全角字符先标准化，标识转为大写。每轮取出前置任务均已完成的全部任务，按标识字符顺序排列为同一层，再进入下一层。
阅读结果
A 无前置、B 与 C 依赖 A、D 依赖 B 和 C 时，分层为 A / B,C / D；稳定顺序为 A、B、C、D。
适用边界
重复任务、重复前置、自身依赖、未声明标识与依赖环都会报错。结果只描述顺序约束，同层不表示资源充足或工期相同。
编辑、重置与复制
输入更改使旧顺序失效。错误时焦点回到关系输入；重置恢复四任务示例。结果复制在本地完成，不保存课程或身份信息。
