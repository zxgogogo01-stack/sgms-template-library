# 029 — Iron Almanac / 铁皮年鉴

高端行业数据年鉴模板。视觉以铁灰装帧、信号红、宋体标题和等宽数字为核心，强调数据密度、方法透明与出版物质感，同时保留清晰的手机阅读体验。

## 页面与功能

- `index.html`：年度封面、四项核心指标、2023–2025 卷切换、区域数据表、关键词筛选、空状态、方法注与引用复制
- `article.html`：完整年鉴读法，覆盖统计范围、指标定义、跨年比较、修订与引用
- `tool.html`：年均复合增长率计算器，含字段级错误、正负/持平场景、逐年等比路径、复制与重置
- `legal.html`：数据性质、来源核验、修订、版权、工具隐私、邀请码与免责声明
- `404.html`：与年鉴装帧一致的缺卷页面
- `css/style.css`：桌面/手机、浅色/深色、键盘焦点、减弱动效与打印样式

## 上线前替换

- `[[SITE_NAME]]`：站点或研究机构名
- `[[SITE_DOMAIN]]`：正式域名
- `[[CONTACT_EMAIL]]`：联系邮箱
- `[[INVITE_CODE]]`：可选邀请码
- `[[COMPLIANCE_NOTE]]`：与邀请、推广或监管相关的补充说明

首页数字均为结构演示数据，不是真实行业事实。正式发布前必须替换全部数字、核对来源，并同步更新统计范围、数据截止日、核对日期和修订记录。

## 后续 AI 的文字接入顺序

1. 先一次性替换以上五个变量/占位符，再逐页接入经过核验的指标、表格、来源、统计口径、截止日期、核对日期与修订记录。
2. 只改文字、数字、链接、日期和数据数组；保留 `ia-` 专属类名、五页结构、响应式断点、表单 ID、ARIA 关系、表格语义和现成交互。
3. 首页三卷切换、搜索空态、引用复制与 CAGR 结果台已经完整搭好。后续 AI 不应重做 UI；如改变指标或计算口径，必须同步修改年鉴读法、凡例、示例和边界说明。
4. 内容接入后逐项复算指标与同比，核对 title、description、canonical、邮件和免责声明，并实测年份切换、搜索/恢复、引用复制、计算错误/增长/回落/持平/零终值/输入后旧结果失效/重置/复制。
5. 最后运行 `node tools/audit-template.js templates/029-iron-almanac`，并与库内其余模板逐对执行相似度检查。

完整视觉、桌面/移动布局、深浅主题和交互框架均已完成；后续 AI 应把 token 用在事实、数字、来源与合规核对上，不在模板 UI 上重复消耗。
