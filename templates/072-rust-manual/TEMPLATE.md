# 072-rust-manual

高端锈色工程拆解手册模板。完整 UI、响应式布局、主题切换、移动导航、文章阅读进度、复制反馈、步骤依赖校验台与本地 404 索引均已搭建；后续 AI 应只替换占位符和正文，不需要重新设计页面。

## 适合内容

- 操作手册、实施指南、知识库、内部流程公开版
- 需要把目标、输入、步骤、依赖、证据与停止条件分开的内容
- 不适合用作收益承诺、自动执行工具或替代官方规则的决策页面

## 文件职责

- `index.html`：总装图首页，含爆炸图、三项原则、四步作业链与行动入口
- `article.html`：长文作业页，含四段程序、风险表格、阅读进度与交接单
- `tool.html`：步骤依赖校验台
- `legal.html`：利益关系、内容边界、工具限制、更正路径与可复制披露
- `404.html`：`noindex` 本地手册索引
- `field-manual.css`：本模板唯一视觉样式
- `rigging.js`：主题、移动菜单、复制、阅读进度、依赖校验和 404 检索
- `robots.txt`、`sitemap.xml`：抓取入口

## 全站占位符

保持 `%%...%%` 语法，仅替换值：

- `%%LANG%%`：页面语言，例如 `zh-CN`
- `%%SITE_NAME%%`：站点名称
- `%%BRAND_EN%%`：短英文品牌名；建议不超过 24 个字符
- `%%SITE_DOMAIN%%`：不含协议和路径的正式域名
- `%%SEO_TITLE%%`：首页搜索标题
- `%%SITE_DESC%%`：首页描述
- `%%SITE_TAGLINE%%`：短标语
- `%%CONTACT_EMAIL%%`：公开更正邮箱
- `%%HERO_EYEBROW%%`：首页眉题
- `%%HERO_TITLE%%`：首页主标题；建议 8–24 个汉字
- `%%HERO_DESCRIPTION%%`：首页主说明；建议 40–90 个汉字
- `%%HOME_FEATURED_LABEL%%`：装配原则区标签
- `%%HOME_LATEST_LABEL%%`：执行顺序区标签

## 只写文字时的顺序

1. 先替换全站占位符。
2. 在首页三个原则卡和四步作业链内换成真实栏目文字，保留节点数量与链接结构。
3. 在文章页替换标题、摘要、四段作业内容和表格；保留 `rm72-operation` 四段骨架。
4. 按真实利益关系修改 `legal.html`，不得删除工具限制、更正路径和免责声明。
5. 更新四个可索引页面的标题、描述和 canonical；404 保持 `noindex,follow`。
6. 不新增远程字体、图片、统计脚本、追踪参数或未经核验的数字。

## 依赖校验台格式

每个非空行严格使用：

`ID | 依赖 ID | 标题`

- 根步骤依赖写 `-`。
- 多个依赖以英文逗号分隔；NFKC 会把全角字母、数字和标点归一。
- ID 归一为大写后必须匹配 `[A-Z][A-Z0-9-]{0,15}`。
- 每步最多 10 个依赖，标题最多 100 个 Unicode 字符。
- 最多 100 个步骤，总输入最多 10,000 个 Unicode 字符。
- 工具会拒绝重复 ID、重复依赖、自依赖、缺失依赖和循环依赖；通过后按拓扑层级显示前 20 步。
- 工具结果只说明编号图，不证明真实操作安全、合规、有权限或能够成功。

## 不要改动的框架

- 不复用其他模板类名；本模板 UI 类统一使用 `rm72-` 前缀。
- 不把动态结果改成 `innerHTML`、模板字符串 HTML 或外部请求。
- 不移除 44px 触控尺寸、键盘 Escape 关闭、错误状态、过期状态、复制反馈或移动端内部滚动。
- 不把占位符示例、披露文字或工具结果描述为真实平台规则、费率、收益、到账时间或资格承诺。
