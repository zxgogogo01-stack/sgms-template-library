# 144 Kintsugi Map

以和纸、黑漆陶碗、金色接缝、靛蓝、朱红、苔绿与修复档案为视觉语言的五页原创静态模板。首页器物修复台、五段观察札记、无向拼片关系图、六项责任卷和档案检索 404 均已完成；后续 AI 只需替换变量、可见文字和演示数据，不需要重新搭建 UI、交互或响应式框架。

## 变量

- `{{LANG}}`：HTML 语言标签，如 `zh-CN`。
- `{{SITE_NAME}}`：站点名，建议 2–12 个汉字或 4–18 个拉丁字符。
- `{{BRAND_EN}}`：英文修复室刊头，建议 4–16 个字符。
- `{{SITE_TAGLINE}}`：首屏短句，建议 10–30 个字符。
- `{{HERO_DESCRIPTION}}`：首屏简介，建议 35–90 个字符。
- `{{OBJECT_SAMPLE}}`：纯演示器物或馆藏编号，建议 2–12 个字符；不得冒充真实鉴定、馆藏、所有权或保险凭据。
- `{{ARCHIVE_CODE}}`：首页可复制的演示档案编号，不得冒充修复报告、鉴定证书、合同、验收或放行文件。
- `{{ARTICLE_META}}`：文章日期、作者或版本信息，建议 10–35 个字符。
- `{{SITE_DESC}}`：页脚摘要，建议 20–60 个字符。
- `{{SITE_DOMAIN}}`：不含协议的域名。
- `{{CONTACT_CHANNEL}}`：公开联系渠道或联系页路径，不要放私人凭据。

## 页面与完整框架

- `index.html`：和纸档案导航、黑漆陶碗与金色接缝首屏、三段修复记录原则、关系图预览和可复制档案编号。
- `article.html`：观察、身份、接缝、材料与交接五段札记，含阅读进度、粘性章节索引、器物结构插图和摘要复制。
- `tool.html`：接缝号与无向片号关系输入、唯一性审计、连通片组、独立闭环、文档状态和完整交接报告。
- `legal.html`：六项互斥展开的鉴定与来源、裂损与片组、材料与处理、安全与使用、价值与流转、隐私与权利责任页。
- `404.html`：最多 80 个 Unicode 字符的本地档案路由，用户输入只通过 `textContent` 反馈。

工具格式为 `接缝号 | 片号 A | 片号 B | 状态`：接受 2–100 条非空记录，总长最多 6000 个 Unicode 字符。接缝号和两个片号均须为 2–24 个 Unicode 字符并拒绝控制字符与格式字符。接缝号执行 NFKC、去除首尾空格、合并内部空格并忽略大小写后必须全局唯一；完全相同与规范化后重复分别报错。

每个片号使用相同的规范化规则参与关系计算；同一规范化片号不能连接自身。同一对片号只允许一条无向接缝，因此 `片 A ↔ 片 B` 与 `片 B ↔ 片 A` 视为重复关系。状态只能为“待描 / 已合 / 封存”。工具建立简单无向图，以深度优先遍历计算连通片组，并按 `接缝数 − 片号数 + 连通片组数` 计算独立闭环数。

除最大连通片组外，每个分离片组生成一项结构提示；每条非“封存”接缝生成一项状态提示。存在两类提示时显示 `REVIEW N`，仅有结构提示时显示 `STRUCTURE FLAGS N`，仅有状态提示时显示 `STATUS FLAGS N`，均无提示时显示 `NETWORK CLEAR`。独立闭环只作图结构信息，不是错误、风险或修复结论。界面最多显示前 40 项提示和前 40 条接缝，复制完整交接保留全部片组、接缝和提示。

## 后续 AI 内容接入顺序

1. 全局替换上述变量，再重写可见标题、段落、演示数据和项目政策；不要删除既有 `data-ki144-*` 属性。
2. 保留五页、黑漆陶碗首屏、金色接缝语言、文章结构、无向关系工具、互斥责任页和移动端框架，不需要为新文案重做 UI。
3. 用经过确认的接缝号、片号和文档状态替换示例；不要让后续 AI 从照片、器形、材质名称、编号或图形猜测真实碎片适配、处理方法、稳定性或价值。
4. 检查 title、description、canonical、Open Graph、robots 与 sitemap 的域名和路径。
5. 在 1440×1000 与 390×844 下逐页测试和纸/漆夜主题持久化、阅读进度、接缝唯一性、规范化自连接、正反向重复、连通片组、闭环、完整复制、重置、互斥责任项和 404 路由。
