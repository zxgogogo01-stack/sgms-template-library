# 112-magazine-cover

## 模板定位

杂志、城市文化刊物、编辑部专题、摄影期刊、品牌内容与独立出版项目。视觉系统由粉色纸张、钴蓝封面、柑橘橙构图块、荧光绿校样标记、黑色网点和横向编辑台组成，不依赖外部图片也能形成完整、高端且具有出版感的界面。

## 后续 AI 接入规则（必须遵守）

本模板的 UI、响应式框架、组件层级、彩色/黑白校样主题、交互、无障碍属性和安全输出已经完成。后续 AI **只替换变量与可见文字，不重建 UI，不改类名，不调整 DOM 结构，不改写 `newsstand.css` 或 `newsstand.js`**。新增封面线、目录项、正文段落、编辑步骤或边界规则时，复制现有封面线、目录行、正文分节、编辑台或版权行组件，只替换内容与真实依据；不得在网站模板 UI 上再次浪费时间和 token。

## 文件

- `index.html`：本期封面、六条目录、四级封面线、编辑流程与工具入口。
- `article.html`：城市光线封面故事，含阅读进度、展开清单与交接复制。
- `tool.html`：批量封面文字适配审计器，所有输入只在本地浏览器处理。
- `legal.html`：文字、事实、图像、人物、字体、隐私与更正边界。
- `404.html`：安全公开页检索与 noindex。
- `static/newsstand.css`：唯一视觉与响应式样式入口。
- `static/newsstand.js`：校样主题、菜单、进度、复制、文字适配与 404 路由。

## 封面文字适配审计器规则

- 每行格式：`文案 ID | 层级(主标题/眉题/摘要/封面线) | 文字 | 每行字符 | 最大行数`。
- 接受 3–80 条非空文案；总输入不超过 12000 个 Unicode 字符。
- 文案 ID 使用 NFKC、大小写与重复空白归一后判重，长度须为 2–16 个 Unicode 字符。
- 层级只能是主标题、眉题、摘要或封面线；每批必须且只能有一个主标题。
- 文字使用 NFKC、大小写与重复空白归一后判重，长度须为 1–200 个 Unicode 字符；ID 和文字不得包含 Unicode 控制字符。
- 每行字符须为 1–40 的无前导零普通整数；最大行数须为 1–8 的无前导零普通整数。
- 估算行数为归一后文字字符数除以每行字符数并向上取整；等于最大行数通过，超过才提示溢出。
- 界面最多展示前 40 条提示与 40 个文字槽，复制报告保留全部结果。
- 机械估算不读取字体，不验证实际字宽、字号、字重、断行、语言排版、版心、输出尺寸、图片关系、设计质量、事实、署名、版权或刊发适切性。

## 验收基线

- 五页各自只有一个 `h1`，1440×1000 与 390×844 均无页面级横向溢出。
- 移动目录首链聚焦，`Escape` 关闭并回焦；彩色/黑白校样主题跨页保持。
- 正文进度到页尾为 100%；封面交接、编辑边界摘要与完整适配报告可复制。
- 动态文字槽、提示和检索结果只使用安全 DOM 文本节点，不使用 `innerHTML`。
- 后续 AI 只能替换变量与文字，直接投入内容生产，不得重建模板 UI。
