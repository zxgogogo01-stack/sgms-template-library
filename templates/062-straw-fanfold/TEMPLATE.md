# 062-straw-fanfold

独立的草编折扇策展模板。首页以折扇主视觉、四片编纂路径、近期抽屉与页签导航组织内容；文章页是可交接的编纂札记；工具页把多行章节标题转换为稳定、唯一的页面锚点。所有 UI 使用 `sf62-` 专属命名空间，不依赖公共 CMS 样式或外部字体。

## 后续 AI 内容接口

后续 AI 只替换变量和可见文字，不需要重做 UI、折扇视觉、响应式、主题、移动导航或锚点算法：

1. 全局替换变量；保留 `sf62-` 类名、`data-*` 属性、控件 id 与五个页面文件名。
2. 首页四片路径与三只抽屉可改写文字；增减内容时复制完整 `article`，不要拆开内部层级。
3. 文章正文可替换，但保留边界表、折页流程、可复制交接单与各章节 id。
4. 工具每次接受 1–50 个非空标题；单行最多 120 个 Unicode 字符，总输入最多 5000 个字符。
5. 工具输出只用于页面内锚点和目录草稿；发布前仍需检查现有页面是否已有同名 id。

## 变量

- `%%LANG%%`：页面语言代码，例如 `zh-CN`。
- `%%SITE_NAME%%`：站点名称。
- `%%BRAND_EN%%`：页眉与页脚使用的英文品牌名。
- `%%SITE_DOMAIN%%`：不含协议的正式域名。
- `%%SITE_TAGLINE%%`：品牌短句。
- `%%SITE_DESC%%`：首页搜索摘要。
- `%%SEO_TITLE%%`：首页 SEO 标题后半段。
- `%%HERO_EYEBROW%%`：首页主标题上方栏目短句。
- `%%HERO_TITLE%%`：首页唯一一级标题。
- `%%HERO_DESCRIPTION%%`：首页主标题说明。
- `%%HOME_FEATURED_LABEL%%`：首页证据带标签。
- `%%HOME_LINKS_LABEL%%`：首页页签导航标签。
- `%%HOME_LATEST_LABEL%%`：近期抽屉标签。
- `%%CONTACT_EMAIL%%`：更正联系邮箱，必须换成真实可达地址或联系路径。

## 锚点算法

- 输入先做 NFKC 归一化、去除行首尾空白并折叠内部空白；空行忽略。
- 保留 Unicode 字母和数字，其他连续字符替换为所选分隔符；英文转小写，组合音标先做兼容归一。
- 空结果使用 `section`；数字开头时可按选项增加 `s-` 或 `s_` 前缀；基础锚点最多 48 个 Unicode 字符。
- 重名按输入顺序追加 `-2`、`-3` 或对应下划线后缀。输出用安全 DOM 节点，不得改为 HTML 字符串拼接。
