# SGMS 静态站模板库

共 160 套可独立运行的静态站模板，供 SGMS 站群客户端导入使用：001–050 为原创精品模板，051–124 为军哥动态首页的忠实静态化版本，125–160 为新增原创模板。

> 2026-09-02 起按正式《返佣站建站工作流》执行 workflow-ready v2 结构返工。旧版“可独立运行”不等于“建站 AI 只填文字即可发布”；当前 v2 就绪进度见 `batches/workflow-readiness-progress.md`。

## 目录结构

- `templates/`：001–160 模板本体；真正的网站文件都在这里
- `tools/`：全库验证、源结构忠实度审计等维护工具
- `batches/`：原创模板的批次设计与差异化记录
- `artifacts/qa/`：历史桌面、手机和明暗模式验收截图；缺少某个编号的截图目录不代表模板缺失
- `README.md`：全库索引与维护约定

## 硬性约定

- 每个模板一个独立目录，位于 `templates/`，命名 `编号-风格名`（001–160，全小写 ASCII）
- 每套模板目录的根层必有 `index.html`（普通文件，非符号链接）
- 纯静态零依赖：无 CDN、无外部字体/图标/图片，图形全部内联 SVG 或 CSS 绘制
- 占位符不含任何真实域名/邮箱/邀请码/费率（各批占位符语法不同，见各模板 `TEMPLATE.md`）
- 换行统一 LF（`.gitattributes` 全仓 `-text`，勿改）；文件名全小写 ASCII
- 模板目录内不放任何脚本文件（.sh/.bat/.ps1/.py）

## 设计与复刻原则

- 001–050 为原创精品模板，按批次保留各自的布局、类名体系、CSS 组织、间距、导航、首屏和交互语言，记录见 `batches/batch-XX.md`
- 051–124 为军哥源模板的忠实静态化版本，不做防同源式重设计，保留源布局、原始类名、结构与可用样式
- 125 起为全新原创模板，每套建立独立概念、信息架构、命名空间、视觉系统与本地工具，后续 AI 只替换变量和文字
- 原创批次间不共用模板样式库；每套模板均可独立复制和运行
- 机器验证：`node tools/check-similarity.js`——任意两模板类名重合度（交集/较小集）≤15%，DOM 骨架与 CSS 属性顺序相似度为参考指标；各批检测矩阵在批次文档里，全局矩阵见验收记录
- 基础体检：`node tools/validate.js`——外链/占位符/文件名/SEO 要素/JS 语法
- 工作流就绪审计：`node tools/audit-workflow-readiness.js`——12 个文章槽位、5 个真工具、7 个合规页、转化链接治理、元数据、内链与发布资产

说明：批次文档使用 ASCII 文件名（`batch-01.md`），因跨平台铁律禁用中文文件名（macOS NFD / Windows NFC 归一化差异）。
