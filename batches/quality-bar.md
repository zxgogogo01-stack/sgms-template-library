# 精品化品质基线（2026-07-26 站主新增要求）

> 所有模板（含已完成的 001-048 回改）必须达到本基线。
> 目标：币圈返佣 SEO 站，用户一眼要觉得「这个站是用心做的」，才会信任并使用邀请码。
> 本基线只约束**视觉品质**，不放松任何防同源约束（类名词汇、DOM 骨架、批次流派、占位符语法照旧）。

## 必达项

1. **排版层级**：标题字号节奏明确（如 2.6/1.4/1.05rem 三级），字重对比（700/600/400），行高与留白有呼吸感；中文字体栈优先精致组合。
2. **配色体系**：每模板一套完整体系——主色、深主色、强调色、两级中性灰、渐变端点；禁止"白底灰字默认感"。
3. **首屏设计感**（最重要）：至少包含两种——多段渐变背景 / 内联 SVG 几何或插画装饰 / 大号数字或徽章元素 / 叠层卡片；首屏必须让人感到"有设计"。
4. **卡片质感**：多层阴影（近影+环境影）、圆角体系统一、hover 微交互（上浮/边框亮起/阴影加深，transition 0.15-0.3s）、可用渐变描边或顶部色条。
5. **转化区 = 视觉焦点**：邀请码卡要做成页面上最精致的元素之一（徽章/票券/玻璃拟态/发光按钮任选），复制按钮有 hover 与按下反馈。
6. **页脚完整**：多栏或多行结构 + 信任要素（数据核对日期占位、免责声明、联系方式），不许一行糊弄。
7. **细节**：链接 hover 有过渡；表格有斑马纹或 hover 行高亮；按钮有 :active 状态；数字用 tabular-nums。
8. **深浅色都精致**：深色模式不是简单反色，阴影与层次要重新调过。

## 禁止

- 页面主体只有"标题+几段灰字+一条横线"的裸排版
- 无 hover 反馈的卡片/按钮
- 单一纯色背景 + 默认字体感（除非该模板流派刻意做「精致极简」，此时排版与留白必须顶级）

## 与防同源的关系

视觉手法（渐变方向、阴影参数、圆角值、装饰图形）**每模板各不相同**——精品化本身也是差异化维度，禁止把某种"高级感套路"复制到多个模板。
