## 流派组合

| 维度 | 本批选择 |
|---|---|
| 布局实现 | float + inline-block 复古门户三栏（与批 3 的双栏报刊骨架不同） |

| 间距节奏 | 无系统随手写 |
| 导航形态 | 右侧边栏 + 顶部细条 |
| 首屏结构 | 栏目框目录直入（门户式，无 banner） |
| JS 风格 | 页尾内联单个 IIFE |

| 缩进 | 2 空格 |
| 引号 | 双引号 |
| 占位符语法 | `[[x]]`（小写，如 `[[site_name]]`） |
| 资源目录 | 无子目录，`base.css` 在根 |
