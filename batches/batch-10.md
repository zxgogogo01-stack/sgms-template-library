# 批次 10（模板 091–100）

## 流派组合

| 维度 | 本批选择 |
|---|---|
| 布局实现 | 纯文档流 max-width 居中为主，数据块用 `display: table`（与批 4 的整页 table-cell 分栏完全不同骨架） |
| 类名体系 | 无类名 + 语义 id 锚点（`#pricing` `#faq`），样式走标签/伪类/属性选择器；兜底 class 每模板 ≤2 个 |
| CSS 组织 | 根目录单文件 `site.css` |
| 间距节奏 | rem 相对 |
| 导航形态 | 顶部极细文字链行（纯 `<a>` 序列，无 logo 块、无容器修饰） |
| 首屏结构 | 无 hero 直入正文（首屏即第一段内容/第一个数据块） |
| JS 风格 | 无 JS（仅 tool.html 允许一小段内联脚本） |
| 注释语言 | 无注释 |
| 缩进 | 4 空格 |
| 引号 | 单引号 |
| 占位符语法 | `%x%`（小写，如 `%site_name%`） |
| 资源目录 | 无子目录，`site.css` 在根 |
