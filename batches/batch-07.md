# 批次 7（模板 061–070）

## 流派组合

| 维度 | 本批选择 |
|---|---|
| 布局实现 | Flexbox 杂志流（横向行嵌套纵向列，flex-wrap 断行；与批 2 的侧边栏骨架完全不同） |
| 类名体系 | 功能前缀，但换前缀集：`m-`（模块）/ `t-`（文字）/ `g-`（全局） |
| CSS 组织 | `styles/` 目录按组件拆分多文件 |
| 间距节奏 | 8px 基准 |
| 导航形态 | 顶部横条 + CSS 悬停下拉（`:hover` / `:focus-within` 实现，无 JS 参与） |
| 首屏结构 | 刊头式大标题 + 副标题（杂志刊头：居中大字 + 期号行，DOM 与批 1 的 hero 不同） |
| JS 风格 | `js/` 目录独立文件，多个具名函数 |
| 注释语言 | 英文，仅关键处 |
| 缩进 | 4 空格 |
| 引号 | 单引号 |
| 占位符语法 | `__x__`（小写，如 `__site_name__`） |
| 资源目录 | `styles/` + `js/` |
