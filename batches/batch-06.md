# 批次 6（模板 051–060）

## 流派组合

| 维度 | 本批选择 |
|---|---|
| 布局实现 | CSS Grid，具名 grid-template-areas（与批 1 的隐式栅格写法刻意不同） |
| 类名体系 | 语义长名（描述性多词，如 `.market-overview-panel`） |
| CSS 组织 | 根目录单文件 `main.css` + head 内少量 critical 内联 `<style>` |
| 间距节奏 | rem 相对 |
| 导航形态 | 无导航单页（页内锚点目录） |
| 首屏结构 | 卡片网格直入 |
| JS 风格 | 无 JS（锚点 + `<details>` 原生交互；仅 tool.html 允许一小段内联脚本） |
| 注释语言 | 中文注释 |
| 缩进 | 2 空格 |
| 引号 | 双引号 |
| 占位符语法 | `{{x_lower}}`（小写下划线，如 `{{site_name}}`） |
| 资源目录 | 无子目录，`main.css` 放模板根 |
