# 批次 9（模板 081–090）

## 流派组合

| 维度 | 本批选择 |
|---|---|
| 布局实现 | CSS Grid 密排瀑布风（`grid-auto-flow: dense` + 跨行跨列，骨架与批 1/6 的规整栅格不同） |
| 类名体系 | 原子式二代：数字刻度类（`.g2` `.s3` `.w6` 风格），每模板自造词汇，禁止与批 5 风格相同 |
| CSS 组织 | 少量变量 + 硬编码混合，根目录单文件 `app.css` |
| 间距节奏 | 4px 基准 |
| 导航形态 | 顶部导航 + 面包屑（实现与批 3 不同：面包屑用 `<ol>` 结构化） |
| 首屏结构 | 卡片网格直入（masonry 密排视觉） |
| JS 风格 | `<details>` 原生交互为主 + 每模板一个小 js 文件，箭头函数风格（`const fn = () => {}`） |
| 注释语言 | 中文，仅关键处 |
| 缩进 | 2 空格 |
| 引号 | 单引号 |
| 占位符语法 | `{X}` 单花括号大写（如 `{SITE_NAME}`，全文精确串替换） |
| 资源目录 | `res/`（`res/app.css` + `res/widget.js`） |
